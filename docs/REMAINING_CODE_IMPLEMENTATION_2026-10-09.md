## 镜像变更水位

- schema 44 增加持久化服务端 epoch、单调媒体修订号、独立元数据修订号。媒体变更表每个类型/ID 只保存最新修订，支持更新、改名、缺失状态和明确删除；删除标记不含路径、文件哈希或描述。
- Local、HTTPS 和命名管道使用相同分页协议。一次分页固定上界；分页期间再次修改的记录在后续同步继续领取。读取在独立数据库连接的事务快照内完成。
- 客户端只在全部媒体页应用成功后保存媒体水位；标签、人物或元数据失败时不推进元数据水位。失败与取消允许重复领取，不会把尚未保存的数据当成已同步。
- 服务端 epoch 变更、客户端水位超前会触发重新校准，并清除已经不属于权威端的镜像引用。旧服务不支持变更接口时继续完整分页核对，不能用“数量相同”代替更新检查。
- 重新校准的差集必须再次查询远端是否存在；分页期间移到上界以后的更新不能被误判为删除。本地模式遇到未归属镜像的 ID/路径冲突时拒绝覆盖，提示使用服务索引模式；不把两个独立数据库的相同数字 ID 当作同一文件。
- 元数据变化仍领取完整元数据快照；未变化时跳过。此机制减少定期传输，不宣称每个元数据实体均使用独立增量事件。
- 对镜像拥有的照片关系执行删除校准，并在应用后重放本地待同步人工编辑。

## 视频内容与手动清除

视频采用单一 `video_contents` 内容实体，路径、来源和存在状态作为多个引用维护。摘要、转录、关键帧、人脸、标签及全文文档不再逐引用复制。已知完整 SHA 忽略字母大小写；未知哈希分别保存，有证据后归并。迁移保留无法合并为当前状态的人工判断历史。详情见[视频内容实现](VIDEO_CONTENT_REFERENCES_IMPLEMENTATION_2026-10-09.md)。

相同内容跨窗口描述使用共享互斥与锁内有效结果检查，避免重复请求；不同内容仍可并发。拼图缓存纳入内容身份，防止同大小、同修改时间的替换复用旧帧。异步模型、转录、探测和关键帧返回时校验原内容，旧响应不得写入新内容。

视频页提供明确确认的索引清除入口。取消并等待关联任务结束，再清理引用、派生缓存、服务任务请求/结果/日志和持久扫描清单；原始媒体保留。其他副本仍引用的共享内容保留，末引用删除时彻底清除。源代理离线或清理失败时保留可重试状态。详情见[清除实现](VIDEO_INDEX_PURGE_IMPLEMENTATION_2026-10-09.md)。

## 跨重启扫描

持久目录清单校验 NTFS 卷、根目录 File ID 和 USN 连续性，重启后只枚举变化目录。仍检查已知目录和媒体元信息，不宣称所有处理都是 O(变化数量)。权限不足、网络盘、非 NTFS、日志断档/超限或损坏缓存均回退完整扫描与内容校验。待核验状态、已确认 SHA 和跨进程清理代际防止中断漏改及旧清单回填。详情见[扫描实现](PERSISTENT_DIRECTORY_SCAN_IMPLEMENTATION_2026-10-09.md)。

应用启动时默认将清单放入已配置的数据目录；显式 `PICER_SCAN_CACHE_ROOT` 优先。自动化测试按进程设置隔离清单目录。
