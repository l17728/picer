# 本机索引与云端 Relay E2E 用例（2026-11-19）

## 环境

- 本机 IndexService、MediaAgent、GUI；
- Relay 测试实例；
- 第二台 GUI 客户端；
- 可控断网、Relay 重启和设备撤销注入。

## 用例

| ID | 场景 | 验收 |
|---|---|---|
| RELAY-01 | 本机模式离线启动 | GUI 查询目录、搜索、分类和缩略图成功，不访问 Relay |
| RELAY-02 | 设备注册与配对 | 仅使用一次性配对码完成注册，错误码不能建立流 |
| RELAY-03 | Relay 远程查询 | GUI 通过 Relay 查询目标本机索引，结果和本机直接查询一致 |
| RELAY-04 | 远程缩略图 | 首次请求从目标本机缓存/MediaAgent 返回，二次请求命中目标缓存 |
| RELAY-05 | 双击原图 | 授权检查、流式读取和预览成功，Relay 不落盘 |
| RELAY-06 | 来源切换 | 本机/服务器切换后目录、分页、分类和缩略图全部刷新，不混用结果 |
| RELAY-07 | 连接断开 | Relay 断线时 GUI 显示离线；恢复后自动重连，不重复写入描述结果 |
| RELAY-08 | 服务重启 | 重启目标 IndexService 后设备重新上线，GUI 可继续查询 |
| RELAY-09 | 设备撤销 | 撤销设备后新请求被拒绝，已有流在安全边界关闭 |
| RELAY-10 | 写入路由 | 描述、分类和人物编辑只写入当前来源，另一来源数据库不变化 |
| RELAY-11 | 同步关闭 | 未启用实时同步时，本机和服务器索引保持独立，查询不触发全量镜像 |
| RELAY-12 | 备份恢复 | 导出的索引快照恢复后无需重新扫描即可查询；媒体缓存缺失时按需重建 |
| RELAY-13 | 缓存加密 | 加密缓存保持目录和文件名，未授权进程无法解码，授权读取结果正确 |
| RELAY-14 | 并发访问 | 两个 GUI 同时查询、加载缩略图和描述，结果不串源、不死锁 |
| RELAY-15 | 安全边界 | Relay 日志不含路径、人物名、描述文本、图片内容或设备密钥 |
| RELAY-16 | 性能基线 | 本机查询不受 Relay 影响；远程首屏和缩略图延迟记录并与长连接基线比较 |
| RELAY-17 | 重放保护 | 重放旧请求序列号、过期请求或重复幂等键，服务拒绝且不产生副作用 |
| RELAY-18 | 断线写入恢复 | 写入中断后恢复连接，只产生一次结果；未提交操作明确显示待重试 |
| RELAY-19 | 密钥轮换 | 轮换设备密钥后旧会话失效，新会话可正常查询，缓存不被误清空 |
| RELAY-20 | 背压与限流 | 并发预取超过限制时排队而不崩溃，取消窗口后所有流和临时文件释放 |
| RELAY-21 | Relay 零落盘 | 检查 Relay 工作目录和日志，不出现索引、路径、查询文本或媒体内容 |
| RELAY-22 | 服务离线隔离 | 目标服务离线时 GUI 明确显示服务器来源不可用，不回退到本机错误数据 |
| RELAY-23 | 本地索引模式 | 选择本地索引后，Relay 只转发请求，不启动持续索引同步，写入只落本机 |
| RELAY-24 | 切换到服务索引 | 切换前暂停新请求，完成一次同步并校验 revision 后才切换查询和写入路由 |
| RELAY-25 | 切换到本地索引 | 先完成一次同步；切换成功后删除远程索引副本和镜像引用 |
| RELAY-26 | 切换失败保护 | 同步失败、取消或断线时保留原模式，不删除远程索引，支持重试 |
| RELAY-27 | 重复切换幂等 | 重复执行同一切换不会重复同步、重复删除或产生跨来源数据 |
| RELAY-28 | 切换一致性门禁 | 同步后 revision、媒体摘要、描述版本和待提交队列一致，且目录、搜索、分类、缩略图探针通过后才切换 |
| RELAY-29 | 检测失败保护 | 任一一致性项不一致时阻止切换并保留原模式，远程索引不得删除 |
| RELAY-30 | 服务索引媒体加密 | 服务索引模式下数据库仍可直接查询；原图、缩略图和媒体缓存内容为密文，授权读取后正确解密显示 |
| RELAY-31 | 多租户数据库隔离 | 两个租户使用同一 IndexService 时，目录、搜索、描述状态和数据库文件完全隔离 |
| RELAY-32 | 多租户媒体隔离 | 租户 A 的缩略图、原图和缓存路径不能被租户 B 读取或命中 |
| RELAY-33 | 多租户 Relay 路由 | 伪造或缺失 tenant/device/session 上下文的请求被拒绝，不会转发到其他租户设备 |
| RELAY-34 | 多租户任务隔离 | 描述、分类和同步队列按租户隔离，取消或失败不会影响其他租户 |
| RELAY-35 | 租户撤销 | 移除租户成员或设备后，旧会话、缓存令牌和媒体流立即失效 |
| RELAY-36 | GUI 删除确认 | 删除索引、远程副本或缓存前弹出确认对话框，取消不会产生副作用 |
| RELAY-37 | Web 删除确认 | Web 管理删除必须先获取一次性确认令牌，重放或摘要不一致时拒绝 |
| RELAY-38 | Web Relay 开关 | 租户管理员可开启/关闭 Relay，中转状态和审计记录正确，关闭后新流被拒绝 |
| RELAY-39 | Web 索引迁移 | 租户管理员可发起索引上移/恢复，任务可观察、可取消，失败保留原索引 |
| RELAY-40 | 原图删除边界 | Web 或 GUI 删除索引不会删除原图；删除原图必须经过现有授权文件操作和确认 |

每个用例均需记录设备 ID、来源模式、请求 ID、耗时、结果码和缓存命中状态；日志不得记录隐私字段。
