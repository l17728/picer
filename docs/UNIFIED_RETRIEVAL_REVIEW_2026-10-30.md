# 统一检索与分类可靠性评审

评审方式：依据现有代码、认证只读探测和既有设计进行架构/一致性/UX/测试四方面静态检查；不是独立专家或真实模型质量验收。

定稿前关闭的设计问题：

1. 不能直接调用现有混合搜索替代问答：它只有单 PersonId，必须统一多人交集及地点约束。
2. 零向量仍请求编码、串行执行和十分钟客户端超时不适合作为必经路径；改为覆盖预检、独立预算和明确降级。
3. “分类一直加载”已有 HTTP 403 证据，不能把性能优化当权限修复。旧授权不静默扩权，修复加载终态及重新授权入口。
4. 离线人工决定需结构版本与人工状态 CAS；幂等重放必须在 CAS 前检查；先验证整批再执行，禁止部分覆盖。
5. 限制取前 200 条不足以实现公平同步；采用冻结高水位 keyset 分页并覆盖 GUI/publisher/回读清理路径。
6. 快结果和最终结果均需问题代次防护，不能因增量展示复活已取消问题。

结论：SDD/UX v1.0 可实施，按上述矩阵验证；实现不满足条目时必须继续列为未完成，不以文档定稿代替验收。
