- 统一不可变人脸评估快照、数据指纹、泄漏分组和独立 train/validation/test 切分。
- 六个候选模型使用同一份基线快照评估，并在排行榜记录每轮结果和历史排名。
- Top 3 主力模型策略已生效；排名 4–6 为备用模型，不接受后续训练提交。
- 训练平台异步任务、GPU Worker、失败恢复、制品哈希/签名校验和客户端应用链路已接入。
- 训练平台、VL、ASR、中文 TTS、IndexService 当前均有本机服务监听。
- 解决了 GPU Worker 标准输出管道死锁和不兼容 GPU Provider 卡死问题。

2. 增加自动数据质量审计：正样本数量、排他负样本、时间跨度、连拍去重和独立验证集比例。
3. 执行 10k/100k 规模索引、搜索、取消和 UI 响应基准，生成可归档报告。
4. 更新多模型实现文档和发布准备文档，移除已经过时的 GUI 阻塞描述。
5. 执行完整非 RuntimeComponent 回归，并记录长耗时测试的最终结果。

## 必须在真实环境完成的门禁

- 真实麦克风/扬声器环境下连续 10 分钟 WebRTC AEC3、插话取消和零误识别验收。
- 同一真实视频上的 Qwen3-ASR-1.7B 与 Whisper 准确率、延迟、内存对照。
- 跨机器 HTTPS Index/Model 服务的证书、SPKI、鉴权、断线恢复和远程图库联调。
- 真实人物数据规模是否足以支持 90% 训练门禁。目前基线最佳验证准确率约为 64.36%，尚不能宣称达到 90%。
