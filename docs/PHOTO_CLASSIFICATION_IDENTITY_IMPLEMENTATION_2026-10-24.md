# 照片分类操作内容身份基础

状态：schema74 开发源码，构建验证中。此阶段只建立内容身份与操作绑定，尚未接入分类按钮、人工字段版本或网络传输，不能作为完整分类同步的交付说明。

照片已有核实 SHA-256 时使用内容身份；尚无哈希时使用图库 epoch 和持久文件版本 UUID。文件大小或修改时间变化会轮换版本，避免旧操作因路径或整数引用 ID 相同而重放到新文件。只有同一文件版本补齐哈希时才提升其操作绑定，之前版本的操作仍不适用于当前内容。

操作绑定保存来源身份。解析时只在相同来源内选取对应内容的规范引用；明确清除引用时，将其操作移交给尚存的同来源引用，最后引用清除则移除绑定。不同来源的相同哈希不参与移交。已有操作重试不会重新绑定到已经替换的内容。

下一步需要将该基础接入独立照片内容身份字段、确认与机器策略两个因果字段、回执迁移、冲突、分页和完整 GUI/来源端往返；尚未完成的部分见[设计](PHOTO_CLASSIFICATION_CAUSAL_SYNC_DESIGN_2026-10-24.md)。协议暂仍为 8；正式接入网络字段时应同步提高协议基线并覆盖旧端边界。

新增测试覆盖无哈希换文件、同版本补哈希、旧操作不重新绑定、同来源规范引用及清除移交、跨来源隔离和末引用清除。结果待构建后记录。

首轮严格构建零警告、零错误，`photo-classification-identity-initial-schema74.trx` 12/12 通过，包含身份基础、照片人物缓存和相关旧库迁移。随后增加仅改路径仍保留无哈希绑定、换文件同时补齐哈希不得提升旧操作两项边界测试，结果待记录。该基础尚无网络字段，不能据此宣称照片分类已完成因果同步。
