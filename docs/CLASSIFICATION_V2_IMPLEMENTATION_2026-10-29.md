## 已启动的实现

- `src/Picer.Core/Classification/presets-v1.json`：family-taxonomy-v1，188 节点，其中 179 个可分类标签、9 个导航节点；191 条关系。包含定义和排除边界，种子不自带自动生效质量资格。
- `ClassificationTaxonomy`：稳定 ID、多父图、is_a/browse/related、环与最大深度检查、歧义别名返回候选。固定九个已登记维度；最长导航路径最多 16 节点，包括停用节点。新增维度必须显式修改契约，不能由模型任意生成。
- `CompiledClassificationFilter`：组内 ALL/ANY、组间 AND、全局排除、父类后代展开和 ID 去重。调用者须先完成授权筛选；纯函数不是权限边界。
- `ClassificationInputFingerprint`：严格 UTF-8、长度前缀、Ordinal 排序与精确去重；输入包含描述、人物、元数据、媒体身份、模型和分类定义版本及发现水位。不同内容的同一证据 ID 拒绝。独立 Python 编码生成黄金摘要进行交叉验证。
- `ClassificationIncrementalPlanner`：未变化跳过、证据变化重评、重试期限、在途重复抑制与后继计划。尚不具备数据库持久化、租约领取或 CAS 发布能力。
- `ClassificationEmbeddingSpace`：模型制品、tokenizer、预处理、维数和归一化必须一致；相同维数不能代替空间身份。

代码复核补齐了最大深度、维度注册表；保留旧海边/沙滩的宽义，新海岸沙滩使用独立 ID；道路、雕塑等只进入设施导航，不扩大旧建筑概念。补充父子显式组合的回归。
