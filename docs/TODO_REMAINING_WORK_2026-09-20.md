## 本轮必须实现（不含主干权重训练）

1. 训练数据质量审计：缺失向量、样本/人物覆盖、负样本、时间跨度、连拍/同源泄漏、重复哈希和分区完整性；结果可通过平台 API 查询并作为提交门禁。
2. 训练 Agent 工具契约和状态可观测性：工具注册表、授权范围、幂等模式、审计事件，以及 queued/running/recoverable/completed/failed/canceled 状态的一致输出。
3. 多模型评测与排行榜历史：同一不可变评测快照、每轮记录、模型保留策略和可复现报告。
4. 性能与回归：10k/100k 索引/搜索基准、取消延迟和 UI 阻塞指标；完整非 RuntimeComponent 回归；RuntimeComponent 在本机资产可用时执行。（2026-09-28 已完成 RuntimeComponent 2+7、流式 Service E2E 和 10k/100k 基准；100k p95 结果作为后续性能观测记录。）
5. 平台与远程服务验收脚本：ModelServer/IndexService 健康检查、HTTPS 鉴权/SPKI、断线重试和制品哈希校验。
6. Qwen3-ASR/VL/中文 TTS 与全双工验收脚本、日志和报告；真实房间 AEC3 10 分钟验收仍属于设备门禁。
7. 文档同步：SDD、用户指南、发布门禁和当前性能结果随实现更新。

## 明确不做

- 本轮不实现或宣称实现 ArcFace/AdaFace/InsightFace 等人脸主干神经网络权重的微调。现有训练是冻结基模之上的原型、阈值和轻量适配策略；权重训练另立项目并需独立 GPU/数据验收。
