# 剩余工作与实现边界（2026-09-20）

本文记录当前盘点结果和本轮开发范围。除“完整人脸主干/网络权重训练”外，其余可由代码、统一模型平台或验收脚本完成的事项均纳入实现计划。

## 已完成并保留

- 多模型人脸向量、模型空间隔离、制品签名/哈希、训练历史与排行榜。
- 统一评测快照、训练/验证/测试防泄漏分组、9 轮校准 Agent、90%/FAR/FRR 门禁。
- GPU Worker、失败恢复、客户端异步提交、视频关键帧复用和 InsightFace 向量补齐。
- AI 检索、视频/音频服务、ModelServer 统一服务入口和基本可观测接口。

## 本轮必须实现（不含主干权重训练）

1. 训练数据质量审计：缺失向量、样本/人物覆盖、负样本、时间跨度、连拍/同源泄漏、重复哈希和分区完整性；结果可通过平台 API 查询并作为提交门禁。
2. 训练 Agent 工具契约和状态可观测性：工具注册表、授权范围、幂等模式、审计事件，以及 queued/running/recoverable/completed/failed/canceled 状态的一致输出。
3. 多模型评测与排行榜历史：同一不可变评测快照、每轮记录、模型保留策略和可复现报告。
4. 性能与回归：10k/100k 索引/搜索基准、取消延迟和 UI 阻塞指标；完整非 RuntimeComponent 回归；RuntimeComponent 在本机资产可用时执行。
5. 平台与远程服务验收脚本：ModelServer/IndexService 健康检查、HTTPS 鉴权/SPKI、断线重试和制品哈希校验。
6. Qwen3-ASR/VL/中文 TTS 与全双工验收脚本、日志和报告；真实房间 AEC3 10 分钟验收仍属于设备门禁。
7. 文档同步：SDD、用户指南、发布门禁和当前性能结果随实现更新。

## 明确不做

- 本轮不实现或宣称实现 ArcFace/AdaFace/InsightFace 等人脸主干神经网络权重的微调。现有训练是冻结基模之上的原型、阈值和轻量适配策略；权重训练另立项目并需独立 GPU/数据验收。

## 外部环境门禁（代码已具备接口，需实机确认）

- 真实显卡容量和长时间 GPU Worker；真实 Qwen3 模型启动与资源占用。
- 真实麦克风/扬声器回声环境下 AEC3、插话取消和零误触发。
- 跨机器 HTTPS IndexService/ModelServer 的证书信任、断线恢复和数据授权。
- 足够且独立的人物标注数据；当前公开基线约 64%，未达到 90% 质量门禁时不得自动应用。
