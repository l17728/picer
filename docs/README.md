## 历史文档的使用规则

带日期的设计、计划和实施报告保留原始事实，页首说明被哪些实现替代。旧版 schema、测试数量、进程 PID、安装目录或“尚未实现”不能直接作为当前运行状态。历史报告中的 `artifacts/` 路径指本机验证证据，构建产物不随仓库提交。

人脸质量、人工 ASR 对照、真人 AEC3、低显存四项旧 P2 验收仍暂停；代码完成、包可启动和真实模型质量达标是不同结论。发布必须另外记录来源提交、部署位置、备份、数据库版本及健康检查。
