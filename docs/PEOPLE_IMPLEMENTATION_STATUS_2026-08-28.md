# 人物识别开发状态（2026-08-28）

## 已完成

- 数据库 v5：视觉分析缓存、人脸、人物、别名、确认/建议归属、拒绝约束、纠错记录和陌生人物候选组。
- YuNet + SFace：本地 CPU 推理，输出归一化人脸框、5 点关键点和 128 维归一化向量。
- 增量缓存：文件大小、修改时间和模型哈希版本一致时跳过重复分析。
- 后台稳定性：单并发、可取消、专用原生推理线程；安全复制 SFace 多维输出，避免原生越界崩溃。
- 人物管理：创建、重命名、别名、确认、“不是此人”、移动人物及按人物返回照片。
- 多人照片：每张脸独立保存和命名；自动建议及无监督分组均具有同图排斥约束。
- 人脸头像：从原图按人脸框裁剪为 160×160，异步生成并缓存到 `D:\PicerData\face-thumbs`。
- 已命名人物匹配：确认向量形成人物原型，只产生“可能是”建议，必须由用户确认。
- 陌生人物分组：未归属人脸形成待确认组，不猜姓名、不自动确认，支持用户整组命名。
- 人物页面：分析、取消、进度、已命名人物、未归类人脸、候选组和逐脸确认。
- 人物详情页：展示该人物全部照片，支持重命名、关系别名、双击照片逐脸纠错，以及二次确认后合并重复人物。
- 人物照片分组：人物详情按与目录浏览一致的时间间隔和场景描述生成锚点，可在“全部照片”和各时间场景组之间切换；逐脸纠错后自动重建分组。
- 人脸精度验证：人物页可打开验证窗口；SFace 使用用户已确认身份统计推荐余弦阈值、误识率和漏识率，检查 5 人 × 20 张样本目标，并可按模型版本持久化后自动应用于人物匹配；YuNet 支持加载/扫描最多 1000 张照片、逐图填写人工人脸数及侧脸/儿童/合影/弱光/旧照片标签，并汇总总体和分类漏检结果。
- 候选组审阅：展示组内各人脸，错误成员可以安全拆出并回到未归类列表，不删除人脸或原照片。
- 人物搜索：主搜索框支持完整人物名称和关系别名，只返回已确认身份的照片。
- 复合人物地域查询：例如“找一下老婆在商洛的照片”，执行已确认人物与 GPS 范围的交集查询。
- 原图定位：照片详情以橙/绿框显示待确认/已确认人脸，支持点击定位、确认人物和纠错；图片限制为 1600 像素解码以控制内存。

## 当前边界

- 未归类人脸聚类已使用基于角距离的精确近邻索引，不再默认截断 5000 张；极端情况下候选边数量仍取决于阈值和相似人脸密度。
- 人物和地域复合查询已完成；“夏天、裙子、山上”等视觉语义由本地视觉标签与已确认的云端描述共同检索。
- 视频人物时间轴使用已确认照片人脸作为本地原型，只显示建议匹配，不向云端发送人物姓名或亲属称呼。

## 2026-09-03 人工标注学习更新

- 人工确认人脸不再只形成单一均值中心；每个人物最多维护 8 个外观原型，以覆盖不同时间、姿态和成像质量。
- “不是此人”和移动纠错进入困难负样本，样本充足后形成按人物自适应匹配边界。
- 自动建议同时考虑检测置信度、脸部相对面积以及第一、第二候选的差距；低质量或歧义样本保持待审阅。
- 更新自动归类会清理过期建议，但始终保留人工确认结果。
- 当前仍属于 SFace 特征之上的决策层学习，没有训练 YuNet 或 SFace 模型权重。
