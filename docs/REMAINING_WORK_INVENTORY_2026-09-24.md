# 剩余工作盘点（2026-09-24）

本文件覆盖 2026-09-24 的代码状态、测试证据和外部验收门禁。

## 已完成

- 普通照片目录、搜索、时间轴、场景窗口使用统一的视口优先缩略图调度。
- 远程服务浏览复用持久化缩略图缓存，支持内容身份去重、空闲批量预取和页面切换取消。
- 视频人物人脸缩略图采用限流批量加载。
- 人物/人脸右侧列表采用当前视口优先和人脸裁剪缓存，并限制并发解码。
- 缩略图滚动偏移、视口范围、批次和错误类型已加入脱敏定位日志。
- AI 问答“牟在商洛的照片”已有成功实测日志：人物和地点条件均识别，地理过滤开启，去重后返回 10 张照片。
- `RemoteThumbnailCacheTests` 定向测试通过。

4. 更新 SDD、用户指南和发布报告，记录新的缩略图调度策略及当前真实测试证据。

## 需要真实环境或真实数据的门禁

1. 人脸训练真实质量：当前公开记录最佳约 64%，尚未达到 90% 应用门禁；排行榜也未积累 20 轮真实训练，不能自动收敛为唯一 Top-1。
2. GPU Worker 长时间、多任务、显存峰值和失败恢复验收。
3. Qwen3-VL、Qwen3-ASR-1.7B、中文 TTS 的真实服务冷启动、热启动、延迟、显存和 ASR/Whisper 对照。
4. 真实麦克风/扬声器环境下 WebRTC AEC3 十分钟全双工、插话取消、播放完整性和误触发验收。
5. 跨机 HTTPS IndexService/ModelServer 在实际图库上的双向增量同步、断线恢复和原图/视频中转验收。
6. 每个主要人物足够的正样本、排他负样本和独立验证集；数据不足时训练制品不得自动应用。

## 明确边界

本阶段不训练 ArcFace、AdaFace、InsightFace、SFace 等基础网络权重。现有训练是冻结基模上的向量、人物原型、阈值和轻量适配策略校准。

## 建议顺序

`完整测试拆分 → Picer E2E 缩略图回归 → 训练质量/排行榜真实数据 → GPU 长时验收 → Qwen3 与 TTS → AEC3 实机 → 跨机 HTTPS 实际图库 → 文档收口`。
