# 全双工语音与人物训练实现记录（2026-09-04）

## 全双工语音

- 统一模型平台新增 `sherpa-onnx-vits-zh-ll` 中文 TTS，接口为 `POST http://127.0.0.1:8090/api/tts/speech`，返回 WAV。
- 模型和运行时只保存在 `D:\VL-models`；TTS 使用 CPU，不与 Qwen3-VL、Qwen3-ASR 抢占显存。
- Picer 语音窗口持续采集麦克风，以宽松 VAD 划分话段并调用配置的 Qwen3-ASR 1.7B。
- 代理回复同时显示并经中文 TTS 播放。播放时麦克风继续工作，近场语音超过播放感知门限会立即停止播报并形成下一轮输入。
- 所有语音指令仍通过 `VoiceCommandAgent` 白名单动作协议，不能绕过目标校验执行写操作。
- 当前回声抑制是播放感知的能量门限。高音量外放等复杂声学环境后续应接入 WebRTC AEC3。

## 人物训练第一阶段

- 启动前生成确定性的不可变快照编号，并展示人物、正样本、人工排他负样本、来源隔离组和基础模型版本。
- 用户确认后才向配置的统一平台提交；非本机地址会明确显示目标主机。载荷不含姓名、照片路径或原图。
- 平台针对每个人物按原型相似度从高到低选择人工明确否定的困难负样本，并按来源组去重；单人物上限为正样本数的三倍且至少保留十个候选。
- 未确认身份的相似近邻只能进入后续的人工确认候选，不能自动成为负样本。
- 平台持久化快照、任务、配方、指标和制品。只有误识率以及正负评估样本数等安全门禁通过才自动应用，否则保留当前版本。
- 已有一键回滚入口；训练和自动归类不得覆盖任何人工确认分类。
