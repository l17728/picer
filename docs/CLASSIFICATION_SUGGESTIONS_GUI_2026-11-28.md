# 从模型建议建立新标签

在“AI 功能菜单 → 照片分类与审核 → 新标签建议”选择一项建议，可查看名称、定义、排除条件、父分类和代表照片缩略图。接受并匹配会建立标签，并按新分类树重新分析这些代表照片。窗口在匹配期间刷新结果。开启“包含待确认建议”后，有匹配照片的新标签会显示去重计数。拒绝或合并建议沿用原审核流程。

接受和创建持久化任务在同一事务内完成。重复提交同一操作会取得原任务。远程操作要求分类管理和分析权限。任务只包含建议记录中的照片，并与已排队或正在分析的同一照片协调。关闭窗口后，服务端任务仍可继续。
