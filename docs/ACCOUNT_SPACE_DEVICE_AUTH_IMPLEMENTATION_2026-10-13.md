# 账号、空间与设备授权实现记录（开发中）

更新：2026-10-13。此记录描述当前工作树候选代码，不代表 GitHub 发布或生产部署。正式版仍为 v1.4.0/schema 45；当前工作树使用 schema 46。

## 已进入工作树的实现

- IndexService 提供账户注册/登录门户、空间创建、会话和设备配对流程；GUI 与 MediaAgent 可导入授权凭据，已有账户可在新电脑加入同一空间。
- 空间数据按独立数据库运行；授权范围在服务端路由处逐请求检查，访问媒体源还需配对的 Agent 连接。多个设备 publisher 的稳定实体标识与变更队列落在本地 schema 46 结构中。
- 客户端首次上传可以从账户连接流程开始注册/登录，再选择允许上传的本地来源；独立机器的来源绑定与发布者身份在空间内分开管理。
- 镜像分页读取使用授权 grant 绑定的只读数据库快照，翻页期间不混入后续提交；快照有容量限制、空闲过期、续期和清除失效处理。未变化时通过 revision 快速返回，不复制整库。
- 服务端索引清除使用账户所有者授权、镜像 epoch 和恢复保护；只移除被明确授权清除的索引及派生数据，不操作源媒体。清除后发布者通过服务端实体清单执行重基线，避免清除项被旧客户端重新上传。
- ModelServer 推理代理使用共享客户端、有界并发/排队、超时与熔断；索引服务 Agent 连接注册、媒体读取和描述任务增加连接生命周期保护。

1. 全量单元和 E2E 通过；覆盖权限拒绝、账号间隔离、撤销、配对重放、服务重启、迁移回滚与同步中断恢复。
2. 以空白数据根及 v1.4.0/schema45 备份分别执行安装/升级演练；验证 DB/WAL/SHM 备份完整、失败时不发布部分迁移状态。
3. 使用真实 IndexService 地址验证注册、已有账户登录、新设备导入凭据、设备撤销、照片与视频索引上传及远程读取；确认只通过授权服务连接。
4. 更新协议、用户文档、安装器、CI 与 Release 工作流；从真实 CI/Release 产物确认各部件及依赖，再按用户既有部署授权进行发布与替换。
