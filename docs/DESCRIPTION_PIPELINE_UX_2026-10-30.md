# 目录描述与同步体验设计

状态：评审修订定稿，待实施验收。关联：[系统设计](DESCRIPTION_PIPELINE_SDD_2026-10-30.md)。

## 两个独立进度

描述进度显示已发现、成功或复用、原有描述跳过、失败；扫描未结束不能把已发现当目录总数。同步进度显示本机已保存、待上传、服务已接收待确认及冲突。取消描述不删除已完成结果或上传队列；同步继续不表示模型任务未取消。

## 取消交互

点击“取消任务”或运行中关闭窗口进入同一入口，立即禁用取消按钮并显示“正在取消，已完成描述会保留”。后到的普通进度不能覆盖取消状态。关闭请求不在工作仍活跃时销毁窗口；工作完成后显示可关闭状态。

等待超过 5 秒时显示当前收尾阶段：等待请求退出、等待数据库保存或等待清理；若无法精确确认，明确写“正在等待当前操作退出”，不能猜测。已完成模型结果正在保存时必须保留保存，不显示“全部已取消”。终态区分取消、服务暂停、预算阻止与真正失败。

同步状态读取失败显示“暂时无法读取同步状态，已保存结果将继续保留”，不能阻断描述或导致窗口永远无法重新开始。清理失败不覆盖原始任务结果。

## 错误展示与恢复

失败列表保留阶段、稳定错误码、可重试性。用户取消不进入失败列表。权限拒绝、输入变化及 HTTP 400 不无条件自动重试。冲突展示为待核对，不能悄悄覆盖较新结果；断网仅保留队列，重启后恢复同步。不得把上传回执显示成已确认双端一致。

## 验收

UI 自动化检查取消按钮即时禁用、取消状态不被进度覆盖、后台状态刷新故障后仍可再次开始、关闭路径与按钮一致；任务测试证明没有新项准入且 worker 全部收敛。模拟长数据库等待时保持诚实的收尾提示。测试使用隔离数据和假模型，不操作现用窗口。
