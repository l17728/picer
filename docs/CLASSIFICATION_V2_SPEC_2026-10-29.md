# 家庭照片多维分类 V2：产品规格与文档入口

状态：v1.0 设计定稿，架构/AI/UX-QA 独立代理评审及修订复核通过，允许启动隔离 M0。2026-10-29。生产仍为 schema92；功能实现和验收状态另行记录。

## 1. 现场问题与目标

只读核对远程权威库：8603 张有效照片，任务显示处理 8603、失败 0，8593 张有视觉向量；机器自动断言 467 条、涉及 338 张、30 个类别（4 个预设内容类别及 26 个相似照片聚类）。户外 287、室内 39；5451 张有人脸检测，3413 张有人工确认人物。元数据断言覆盖全部照片，导致旧“无分类”统计为 0。这些是某次现场快照，不是设计的固定数据或验收期望。

解决：内容覆盖不足、类别过粗、人物证据割裂、描述更新不触发完善、分类项与类别/照片计数混淆、逐条审核列表缺乏全局浏览视角。任务完成必须与语义分析成功、有效内容覆盖分开。

## 2. 已确认产品决定

- 预设通用家庭照片分类体系，允许 LLM 提出动态扩展；图片、有效描述、确认人物及可核验元数据共同作为证据。
- 一张照片允许多标签；同一标签允许多个浏览父级。上下位、多位置展示、语义相关三种关系不能混为一谈。
- LLM 判断语义归类、同义关系、候选群体共同主题及动态类别；向量只提供候选召回，不直接决定类别或身份。
- 新增“增量更新分类”，处理新增照片、描述/人物/证据变化、受影响规则版本及可重试失败；无变化不重复推理。
- 分类树 checkbox 组合筛选，缩略图墙点击原图，照片去重。人工决定和已有因果同步规则保持最高优先级。
- 本阶段范围为已索引照片；视频保留现有功能，后续沿用协议但不计入照片覆盖率。

## 3. 产品边界

现有“整理已有结果”保留，无新模型调用。V2 增量推理使用独立启用的分类模型配置，优先本机可用视觉语言模型；既有描述授权不自动等同于分类云端授权。按钮先扫描并给出范围、原因、预计调用数及预算，再按已有授权执行；无有效授权时由用户启用，不暗中切换云端。

离线且有本地模型时支持完整推理/分类/浏览；没有模型时可以浏览、人工维护、整理既有证据，待推理项明确保留。没有描述可先用图片分类，后续描述补齐再更新。不能声称只凭文字确定图片中出现的内容。

机器新结果默认待确认；只有固定模型、提示、类别和校准版本通过质量门禁的类别才能启用自动生效。不能以 LLM 自报 confidence 绕过质量门禁。既有机器结果保留 legacy 来源和版本，避免升级后被当作已通过新门禁。

## 4. 必须满足的体验

打开分类页可看到全库内容覆盖、标签树及照片预览；切换条件不调用 LLM。组合条件可解释、可清除，数量与实际照片集合一致。增量任务有可恢复检查点，窗口关闭不取消服务端任务，暂停/取消保留已提交结果。动态候选可查看代表图及理由，支持确认、合并、拒绝、改名和移动浏览位置。
