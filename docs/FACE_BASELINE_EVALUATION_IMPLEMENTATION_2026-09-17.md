## 目的

排行榜的基线必须来自不可变、可复现、与训练数据隔离的评估快照。本实现不创建合成样本，也不把历史训练轮次冒充基线。

## 流程

1. 客户端只提交不可变评估快照；多模型基线评估由统一模型平台和排行榜负责。
2. 客户端冻结 `FaceEvaluationSnapshot`，按人物、原图/连拍组和视频来源划分 train/validation/test。
3. 以索引中已有的人脸模型作为裁剪框来源；平台可用但本地缺失向量的模型通过统一模型平台批量补齐。
4. 对每个模型按同一快照读取其独立向量。任一模型覆盖不完整、维度不一致或缺少验证集时，整个基线提交停止，不生成部分基线。
5. 通过 `/api/face-training/model-rankings/baseline` 以同一个 evaluationId 并行提交全部模型。
6. 任务在平台异步执行，结果写入排行榜；客户端显示快照、评估编号和平台地址。

## 数据约束

- 向量按 `modelVersion` 隔离，禁止跨模型复用。
- 评估快照的分组保证同一原图、连拍组和视频关键帧不跨分区。
- 基线不自动应用模型，仅用于排行榜和后续新旧策略比较。
- 真实数据不足时 UI 明确报告原因，不能以占位数据填充。

## 回归检查

- 解决方案 Debug `--warnaserror` 构建通过。
- 基线按钮只在异步准备/补齐完成后提交，期间不会阻塞 UI。
- 平台端点仍校验至少两个人物、训练/验证样本、向量维度和泄漏分组。
