状态：v1.0 设计定稿，架构/AI/UX-QA 独立代理评审及修订复核通过，允许启动隔离 M0。2026-10-29。生产仍为 schema92；功能实现和验收状态另行记录。

## 1. 页面与入口

2026-10-30 实现补充：分类读取及同步网络请求超过 20 秒结束等待并提示重试，现有结果与待同步操作保留。缺少授权时提示在设备授权中启用分类权限；无有效基线的空响应不得显示同步成功。并发刷新时仅完成已回读确认的操作，后到操作继续显示待同步，不因旧响应回退缓存或审核状态。

沿用“AI 功能 → 照片分类与审核”，主视图由逐条断言改为“分类浏览”；另设“待确认与动态候选”“任务记录”“逐项审核”。不移除原人工确认/拒绝功能。页面上半部展示授权范围和覆盖指标，左侧多维标签树，右侧去重缩略图墙，底部是当前筛选与加载状态。

## 2. Checkbox 的语义

checkbox 仅用于筛选，不会确认/删除标签。默认满足全部选中项，支持满足任一项。一个父级代表“它自身或任一下属标签”；例如选择森林和人物表示两者都满足。选择两个兄弟标签后可切换任一以取并集。排除项独立显示，排除优先；造成空集时指出冲突条件，不擅自放宽。

用户勾选父级直接建立一个父级条件，不生成大量子条件。父级实心勾选表示被显式选中，半选表示部分后代条件被选中；键盘/辅助技术朗读必须区分“整类选中”和“部分子类已选”。删除父级条件不删除独立勾选的子级条件。重复浏览位置共享同一个选择状态，避免一处勾选一处未勾选。

树节点显示当前范围下的去重照片数，组合结果区显示实际命中数，不让用户相加节点数当总数。命中总数与分页项使用同一快照。标签别名可搜索，展示命中的规范标签与完整路径；被合并标签的旧筛选自动定位新 ID 并提示。展示重命名不会改变已保存筛选。

三态交互不使用 WPF 默认循环推导查询：未选/半选节点按 Space 或点击均变为“显式选中整类”，原有后代显式条件保留；已显式选中的节点点击只移除该节点条件，后代条件仍在。父级选中时未独立选择的子级显示“由父级包含”标识而非伪装成显式勾选；用户可在条件条中单独管理，所有同 ID 浏览位置同步。排除使用独立按钮/条件条，禁止把第三态当排除。

保留旧“聚类高级设置”时更名为“相似照片候选设置”，说明滑块仅影响候选召回，不能代表 LLM 类别判断的正确率。只有相似群组的照片仍属于未识别内容，不能用“动态分类”文案混淆动态语义标签。

## 3. 预览和详情

虚拟化网格，每次最多 200 项按需加载，旧筛选返回不覆盖新结果。缩略图显示类别来源徽标和建议状态；单击打开已有图片查看器读取原图，支持键盘 Enter，Esc 返回并保留筛选/滚动位置。原图不可读时仍保留缩略图及分类信息，显示“来源暂不可用”，不删除索引。重复内容引用遵循图库现有引用语义，不因同哈希静默合并。

详情分“程序证据”“模型建议”“人工决定”，说明图片/描述/确认人物等证据来源，提供确认、不是此类、恢复待确认、改类。LLM 自报分数不显示为精确正确率。批量修改显示影响的去重照片与关联条数，并使用既有人工决定及冲突处理流程。

## 4. 增量按钮与任务流程

点击“增量更新分类”先执行轻量扫描，展示新增照片、描述更新、人物/元数据更新、规则变化、重试等原因计数与去重总数；原因可重叠，明确不可相加。允许切换范围与只处理某类原因。无变化显示“当前范围没有需要更新的照片”，不调用模型。

已有有效模型授权及预算内可开始；第一次启用或扩大云端用途时明确模型位置、将发送的材料、预计调用数和预算，沿用用户授权。扫描不调用模型。大批量模型/体系更新独立显示“预计重评 N 张”，不在启动页面时自动运行。

进行中显示待领取、推理中、已提交、未识别、失败、过期重排和待同步，分别显示“本机已保存”“服务端确认”“已回读一致”，不能将上传回执等同于全链路完成。暂停停止领取新项，显示“正在暂停，等待在途结果保存”；取消保留完成结果，关闭服务端任务窗口不取消任务。本地 GUI 退出后任务中断、下次可续跑，不承诺本机无人运行时仍在推理。

完成显示“截至本次扫描，已处理 X / 待处理 Y；期间新增 Z 项待下次更新”，区分有内容标签与推理无标签。存在失败显示部分完成，提供原因和重试入口；预算耗尽显示暂停与预算原因。无图片、无描述、未识别、身份变化和模型不可用采用不同状态文案。

当前状态按 SDD §11.4 的优先级组成互斥主分区；可同时保有历史分类但本次失败，界面显示“更新失败，历史结果保留”，不清空预览，也不把旧结果算作本次成功。类别覆盖显示人工/已验证自动、历史、待确认三个可重叠层，点击指标按相同口径筛选。

## 5. 动态类别候选

候选卡展示名称、所属维度、建议浏览路径、代表图、LLM 提出的共同特征、已验证成员数量及未验证数量。候选不以高分伪装成自动有效类。审核操作：接受新类别、合并已有标签、修改定义/归属、暂缓、拒绝；接受类别结构不等于确认所有照片归类，成员需逐项验证。跨分支展示展示相同标签 ID；相关关系单独说明，不进入父级包含逻辑。

模型推荐森林与露营相关时，两者作为独立标签。允许露营有多个合理导航父级，不能把森林当作所有露营的上位类别。名称冲突、循环关系、版本冲突和疑似重复会阻止提交，并提供可修正说明。

## 6. 无障碍、空态与保留状态

树支持方向键展开、Space 勾选、Shift+Tab 返回筛选，带角色/选中状态/完整路径/计数的 AutomationProperties。网格支持键盘移动和 Enter 原图，焦点返回原缩略图。颜色之外使用文字/图标区分来源；计数与任务进度变化节流朗读。加载、离线、无命中、无标签、无授权、分页快照过期分别显示，取消重试不会清空已有结果。窗口尺寸变化时允许折叠树；不强制把细标签全部平铺。

## 7. 定稿交互补充

- 支持“添加条件组”：当前树勾选作用于当前组，组内全部/任一，组间全部；最多8组、每组32条件。可表达人物 AND（森林 OR 草地）。半选和显式勾选依据当前组显示，跨组条件在顶部可见，不假装支持任意嵌套。
- 普通模式点击缩略图打开原图；点击“选择照片”进入批量模式，照片框独立于标签筛选框，Space选中、Enter查看，支持当前页Shift区间选择。跨页选择保存稳定引用ID和快照；切换筛选默认清空并提示，若有未提交操作先保留确认机会。批量审核必须明确目标标签。
- “增量更新分类”按钮只扫描并显示计划，扫描结束模型调用数仍为0。计划页的“开始处理 N 张”才执行；已有授权不重复弹授权框。范围、原因过滤、模型、预算或作用域版本变化使旧计划失效。估算分别列出单图、候选群组及重试上限，预算总上限覆盖全部调用。
- 图按展开路径 occurrence 懒加载，选择按 label_id 共享；同页默认最多500个展开路径实例，超过时折叠/分页，不无限展开 DAG。树聚合批量读取，不逐节点发远程请求。
- 图片网格使用真正可回收的虚拟化容器，不把普通 WrapPanel 当作虚拟化。可见区域外只保留有限预取，缩略图 LRU 有界（初始128MB，可按机器配置调整）；连续分页后容器和解码图片不会随总图片数线性累积。
