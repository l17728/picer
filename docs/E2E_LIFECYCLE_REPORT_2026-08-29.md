## 本轮发现并修复

主工具栏在 1200 像素窗口下会把“任务中心”之后的入口放进 WPF 溢出区，UI Automation 与部分辅助技术无法发现。现已改为始终可访问的“文件 / AI 功能 / 工具”主菜单，高频索引和清理操作继续保留在工具栏；修复后的桌面 UI 测试通过。

## 外部服务边界

云端视觉和 WebDAV 使用可控 HTTP 服务验证请求格式、认证、脱敏、缓存、预算与失败处理，不调用真实第三方账号，因此测试结果不承诺某个外部供应商在任意时刻可用。Picer 的本地导入、搜索、人物、CLIP、Florence、视频转写、备份和诊断不依赖这些外部服务。
