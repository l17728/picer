# 全双工摄像头/麦克风验收用例

## 环境

- 摄像头：FHD 1080P（Windows 设备状态 OK）
- 麦克风：FHD 1080P MIC（Windows 设备状态 OK）
- 中文 TTS：统一平台 `/api/tts/speech`，Sherpa VITS
- 音频采集：FFmpeg/NAudio

## 用例

| 编号 | 场景 | 验收标准 | 状态 |
|---|---|---|---|
| FD-001 | 同时打开摄像头和麦克风 | 5 秒内成功产生音频和视频流 | 通过：1920×1080、30 FPS、44.1kHz 音频 |
| FD-002 | TTS 播放 | 统一平台返回有效 WAV，客户端可播放 | 通过：实测生成 WAV |
| FD-003 | 播放期间用户说话 | 检测到语音后停止 TTS，并取消当前 Agent 轮次 | 已实现，需真实外放复测 |
| FD-004 | 连续插话 | 连续两次插话不会死锁，恢复监听 | 需实机验收 |
| FD-005 | 静音/环境噪声 | 不应误触发插话取消 | 需实机验收 |
| FD-006 | 扬声器外放回声 | 用户未说话时不应把 TTS 当作用户语音 | 当前能量门限策略；AEC3 未接入 |
| FD-007 | 取消/关闭窗口 | 释放麦克风、扬声器和识别请求 | 已实现，需实机回归 |

## 当前结论

设备可用性和 TTS 链路已通过。当前全双工仍使用播放期间能量门限，不等同于 WebRTC AEC3；FD-006 必须在真实扬声器外放环境中通过后，才能宣称 AEC3 级别验收完成。
