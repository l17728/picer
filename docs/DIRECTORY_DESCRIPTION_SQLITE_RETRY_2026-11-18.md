# 目录描述 SQLite 争用修复（2026-11-18）

## 根因

模型请求正常返回 HTTP 200，失败集中发生在结果写入阶段。目录描述的模型调用允许并行，而同步、人物投影或 UI 写入可能同时持有 SQLite 写锁；短暂 busy/locked 冲突会被保存阶段记录为 `analysis_failed`。任务协调器在连续服务错误达到阈值时会停止继续派发，因此用户看到任务中途停止。

## 修复

`CloudVisionAnalysisService` 保留模型并行，把数据库状态读写限制在专用闸门内。对 SQLite 错误码 5（busy）和 6（locked）增加指数退避重试，最多 7 次，延迟 250ms、500ms、1s、2s、4s、8s；取消请求仍会立即结束等待。模型调用不在数据库闸门内，不会因为写入重试占住模型并发槽。

这样短暂的数据库争用会自动恢复，只有持续失败才进入失败清单；已有成功结果仍会被跳过，失败项可以继续重试。
