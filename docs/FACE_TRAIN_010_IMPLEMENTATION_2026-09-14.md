训练制品通过门禁并由用户确认应用后，客户端执行以下闭环：

1. 写入新人物原型与阈值，保留人工确认分类不变。
2. 在数据库工作线程使用新策略重新计算未确认候选。
3. 在进度条显示已处理/总数，避免阻塞 UI 线程。
4. 自动刷新人物模块，使候选分组立即反映新结果。

回归验证覆盖人工纠错保护、建议保持待确认、多原型与负样本策略、制品应用/回滚；相关测试 5 项通过。解决方案在 `--warnaserror` 下构建通过。
