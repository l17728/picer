## 1. 计划原则

- 优先消除误导性和不可恢复风险，再扩展功能。
- 每项任务必须包含用户可观察的验收标准和自动化测试。
- 性能任务必须先建立可复现基线，不以开发机主观感受验收。
- 下列工作量使用相对规模：S（1–2人日）、M（3–5人日）、L（1–2周）、XL（需进一步拆分）。

## 2. 里程碑概览

| 里程碑 | 目标 | 退出条件 |
|---|---|---|
| M0 安全基线 | 产品不再误导或未经审阅处理文件 | SAFE任务全部完成 |
| M1 可用图库 | 首次建库、浏览和搜索达到基本产品体验 | UX与SEARCH核心任务完成 |
| M2 智能整理 | 标签、问答、重复审阅形成闭环 | SEM与DUP核心任务完成 |
| M3 规模化 | 10万图库满足性能预算，WebDAV安全可靠 | PERF与REMOTE任务完成 |

## 3. M0：安全基线

### SAFE-001 禁用自动重复处理命令（S，P0）

- 移除或禁用“保留最大/最新/最早/最高分辨率后立即处理”的执行行为。
- 暂时保留时改名为“推荐保留最大/最新/最早/最高分辨率”，仅改变审阅建议。
- “删除勾选组”在删除计划上线前不得执行文件或索引修改。

验收：运行任何识别或推荐命令后，原文件、索引和缩略图均不变化。

### SAFE-002 统一删除术语和 API（M，P0）

- 将 `IndexEngine.RemoveAsync` 重命名为 `RemoveIndexRecordAsync`。
- 全局区分“从索引移除”和“移到回收站”。
- 消除 DuplicateViewModel 中重复调用数据库删除的问题。

验收：编译期不存在语义模糊的 `RemoveAsync`；仅删除索引时界面不显示“文件已删除/已释放空间”。

### SAFE-003 实现缺失文件身份校验（M，P0）

- 重新定位前计算并比较 SHA-256。
- 哈希不同、读取失败、文件变化时阻止绑定并给出明确原因。
- 增加单文件和根目录匹配的服务层接口。

验收：相同内容不同路径可恢复；相同扩展名但不同内容不能自动恢复；相关自动化测试齐全。

### SAFE-004 建立回收站操作边界（L，P0）

- 新增 `IUserAuthorizedFileOperation` 和 Windows 回收站实现。
- 建立不可变删除计划、逐项结果、冲突检测和部分失败处理。
- 只有回收成功的项才能删除索引及派生缓存。

验收：未确认时零文件操作；回收失败时索引保留；成功和失败项均有准确摘要及恢复说明。

验收：新用户可完成建库；取消后数据一致；1万图片扫描全程可见阶段和数量。

### UX-002 统一导航和任务反馈（L，P1）

- 建立全部照片、文件夹、标签、相册、重复与相似、缺失项目导航。

- 增加错误、空结果和完成状态。

验收：日常浏览无需打开日志；所有后台失败均可被用户发现并采取行动。

### UX-003 虚拟化照片网格（L，P1）

- 抽取复用 `PhotoGrid`。
- 实现虚拟化多列布局、缩略图尺寸调整、回收和可见项加载。
- 支持键盘导航、多选和上下文菜单。

验收：10万结果不一次性创建全部 ViewModel；滚动指标达到性能预算；目录和搜索行为一致。

### SEARCH-001 FTS与分页搜索（L，P1）

- 修正 FTS schema/触发器并用 `MATCH` 查询。
- 引入 keyset 分页、总数和已加载数。
- 新查询取消旧查询，结果批量切换。
- 使用查询计划补充必要复合索引。

验收：不得静默限制5000条；10万与100万基准达到搜索预算。

### SEARCH-002 筛选器与结果解释（M，P1）

- 接入日期、相机、尺寸、文件大小、来源、标签和缺失状态。
- 使用 chips 展示已启用条件。
- 显示命中依据、总数、加载数和无结果建议。

验收：所有现有 `SearchFilters` 能从 UI 配置，组合筛选具有自动化测试。

## 5. M2：智能整理

### DUP-001 重复审阅工作台（L，P0）

- 分离“完全重复”和“视觉相似”。
- 每张候选展示路径、大小、尺寸、日期、来源、算法和相似度。
- 支持未决定、建议保留、保留、删除、暂不处理状态。
- 推荐规则只填充建议，不产生文件或索引操作。

验收：用户必须明确决定所有待删除项；关闭、取消或未决定均不修改任何数据。

### DUP-002 删除方案确认与执行（L，P0，依赖 SAFE-004）

- 汇总用户选中的文件、容量和冲突。
- 默认按钮为取消，确认后才调用回收站服务。
- 展示逐项成功、失败、实际释放空间和恢复说明。

验收：执行范围与确认快照完全一致；文件变化时阻止对应项；部分失败不会错误更新索引。

### SEM-001 标签与AI建议入口（L，P1）

- 将已有标签、相册、建议标签能力接入主界面。
- 区分用户标签和 AI 建议。
- 支持接受、拒绝、编辑和批量处理，并即时刷新搜索结果。

验收：对单图打标后无需重启即可搜索；拒绝的建议不会自动重新出现。

### SEM-002 统一检索与问答（XL，P1）

- 定义结构化搜索与自然语言问答的模式切换和降级策略。
- 问答返回图片结果及命中依据。
- 明示本地模型或外部服务，并在外发内容前请求授权。

验收：不支持的问题不会伪装成零结果；所有结果可解释；隐私授权有自动化流程测试。

### MISSING-001 批量重新定位（M，P1，依赖 SAFE-003）

- 支持指定新根目录。
- 预览匹配、冲突和未匹配数量。
- 扫描或网络失败不得触发缺失对账。

验收：移动整个目录后可一次恢复；不同内容不会被误绑定。

## 6. M3：规模化与远程来源

### PERF-001 性能基准与可观测性（M，P1）

- 创建1千、10万、100万混合图片基准集生成器或清单。
- 增加启动、搜索、索引阶段 EventSource 指标。
- 建立 SSD/HDD/WebDAV 可重复测试脚本和报告模板。

验收：CI或专用性能环境可稳定复现基线，报告包含 p50/p95、吞吐、内存和GC。

### PERF-002 异步启动和首屏分页（L，P1）

- 窗口先显示，再加载聚合计数和首屏。
- SQL聚合替代全记录计数。
- 移除逐项 ObservableCollection 启动风暴。

验收：10万图库达到启动预算，加载期间窗口持续响应。

### PERF-003 分阶段索引流水线（XL，P1）

- 流式枚举、短批次事务和安全 missing reconciliation。
- 快速元数据/预览阶段与后台哈希/识别阶段分离。
- 下采样复用、有界 CPU/I/O 并发和端到端取消。

验收：取消实际停止小于1秒；无变化扫描和新图片吞吐达到批准的基准目标；峰值内存受控。

### PERF-004 缩略图缓存与加载队列（L，P1）

- 目标尺寸解码、版本化缓存键、原子写、single-flight和LRU。
- 建立有界、可取消、可见项优先的加载队列。

验收：离屏项不持续占用线程和内存；首屏、滚动和缓存容量达到预算。

### REMOTE-001 WebDAV流式与错误隔离（L，P0）

- `ResponseHeadersRead` 流式落盘并原子进入缓存。
- ETag/mtime/size缓存失效，目录枚举有界并发。
- 枚举失败明确返回失败状态并阻止缺失对账。

验收：20/100ms模拟RTT和500/超时/权限错误均有覆盖；远程失败不会把全源标为缺失。

## 9. Definition of Done

每项任务只有在以下条件全部满足时才算完成：

- 实现与产品安全原则一致。
- 单元、集成及必要的UI自动化测试通过。
- 用户可见文案和失败状态经过检查。
- 涉及性能的任务提供前后基准数据。
- 涉及数据库的任务提供迁移与回滚方案。
- 文档、代码和测试使用同一术语。
