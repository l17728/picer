# 远程索引元数据同步修复（2026-09-22）

## 问题

远程索引服务此前只接收图片和视频记录，没有接收标签、相册成员关系、图片标签关系和地理层级。因此远程客户端能看到媒体总数，但 Apple 相册、时间线相册和地理目录为空或明显少于本地。

## 实现

- 新增 `/api/sync/v1/metadata`，同步标签、相册、相册成员、图片标签和地理层级。
- 图片同步使用原索引 ID，确保关联数据不会因远端重新分配 ID 而失效。
- 新增 `/api/gateway/v1/metadata` 及客户端网关协议，远程镜像启动时拉取关联数据。
- 本地、HTTPS 和命名管道网关统一提供元数据快照能力。
- 同步保持幂等，可重复执行，不修改原始文件。

## 验收

- 服务端自包含 Linux 部署并重启成功，`/health` 返回 200。
- 远程相册接口已返回“相机: Apple”和时间线相册。
- 元数据快照已成功返回约 1.8 MB 关联数据。
- `dotnet build picer.sln -c Debug --no-restore --warnaserror`：0 警告、0 错误。
- `GatewayContractTests`：47/47 通过。

远程客户端重启或执行一次“同步本地索引”后，会将元数据写入本地 `remote-mirror.db`，目录树、相册和地理节点即可与本地一致。
