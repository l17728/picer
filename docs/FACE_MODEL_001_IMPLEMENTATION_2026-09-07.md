新增 `FaceModelReviewService` 作为底层模型替换的只读安全门禁。候选模型必须先证明轻量适配器不足，并同时满足授权已知、检测召回不下降、身份误归率不恶化、CPU P95/内存不超过基线 1.5 倍、DirectML 能力不意外丢失和迁移成本可接受。服务只生成评审结果，不下载、替换或激活模型；激活仍需独立评测快照、门禁和用户确认。

运行组件服务继续负责 YuNet/SFace 固定文件大小、SHA-256 和实际加载自检，确保候选模型不能绕过完整性验证。
