# 视频前台调度与分类检索接入实施约束

状态：下述约束已落实开发，最终验收及部署见[收尾记录](MEDIA_EXPERIENCE_COMPLETION_2026-10-31.md)。视频局部读取最终采用独立的版本化详情缓存，不向镜像执行局部 authoritative 替换；后台同步继续负责镜像收敛。分类任务启动不等同于整库打标完成。

## 视频详情

保留后台镜像同步。新增单视频元数据读取契约，必须按授权的视频引用读取，携带索引 epoch、内容身份和修订号。局部回写仅处理该视频范围，不能传入全库 authoritative 清理。现有本地 SQLite 和已校验帧缓存先显示，未同步与服务端确实无结果分别表示。

前台选择期间暂停后台分页提交之间的后续请求，正在提交的事务完成后让出。当前视频元数据、可见帧优先；切换视频取消旧请求，完成的缓存保留。人物目录与统计独立加载，不阻塞摘要和转录。恢复后台同步时保留游标，不重新全量扫描。

## 分类与问答

统一读取当前有效分类证据：人工确认、新版当前输入指纹匹配的结果、显式允许的建议。旧指纹、拒绝、撤回和停用类别不得作为当前分类证据。远程 GUI 必须读取对应空间的分类副本，不能只查询本地空的 classification_v2_labels。

分类作为独立召回通道融合，必须复用人物交集、时间、缺失文件和 GPS 冲突约束；不能把分类召回直接并入结果而绕过硬条件。名称及别名用于召回，稳定 ID 用于关联。命名人物分支继续使用人工确认人物关联，不作为模型生成身份。

复核证据附带标签来源、确认状态和版本；不能仅把标签写进一段模型提示词便宣称已接入检索。全文索引投影与描述更新相互独立，避免分类更新覆盖原有描述文本；标签改名、合并、拒绝及文件内容变化必须使派生检索结果失效。

## 验收

- 后台同步中的当前视频插队、连续切换取消、热缓存离线显示、局部更新不清除其他视频及人工标注。
- 分类独立召回在描述未出现该词时仍能命中；人物、时间或 GPS 冲突必须排除。
- 旧分类指纹、拒绝标签和未授权建议不召回；远程副本与本地模式采用一致语义。
- 现场核对现有全量分类任务的成功/失败/剩余数量，部署前保留可恢复进度。
