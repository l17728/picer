# FACE-REPORT-001（FACE-EVAL-003）实施记录

## 已实现

- `FaceLearningReportService` 只读汇总人物确认正样本、排他负样本、待确认建议、向量原型数量、质量覆盖和模型版本覆盖。
- 报告按人物生成样本不足、负样本不足、无向量原型和质量偏低风险，并从“已确认人物 + 被拒绝人物”关系统计混淆对象。
- 人脸精度验证窗口新增“人物学习报告”页：报告生成在数据库后台线程执行，界面显示总体风险、逐人物风险和混淆对象；可导出 JSON。报告不会改变归属、索引或人工标注。
- 报告契约使用算法中立字段，不假定 SFace；后续切换 YuNet/SFace、ArcFace 或其他算法时只需替换输入仓储/策略，报告格式保持兼容。

## 本地 HTTPS 模型服务

AI 设置默认增加“本地 HTTPS 模型服务”（`https://127.0.0.1:8443/v1`），提供 Qwen3-VL 8B 与 Qwen3-ASR 1.7B 模型选项。它与已有本地 HTTP 服务并存，用户可按照片描述、视频转写、AI 问答等功能分别选择服务商和模型。服务端证书和端口由本地模型服务负责，客户端不会绕过证书校验。
