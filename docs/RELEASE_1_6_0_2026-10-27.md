## 本轮内容

- 来源索引与照片空间的双向同步、持久化身份映射、断线续办和按来源隔离。
- 全空间一键巡检、同步与修复；离线来源保留待办，恢复连接后续办。
- 分类、标签、相册、人物、视频人工决定、照片和视频分析结果、候选组及场景描述的同步与冲突保护。
- 远程人物整理和训练应用在权威服务执行；来源训练工件的应用回执返回原来源，保留原始工件及模型版本隔离。空间混合模型不自动复制给来源电脑，见[归属边界](TRAINING_APPLICATION_SYNC_IMPLEMENTATION_2026-10-27.md)。
- 照片、人脸及同步批次 SQL 命令复用，人工元数据分页查询优化，持续有界压缩已完成日志。

## 兼容与升级

本轮源码为 schema91、元数据协议 14。GUI、MediaAgent 与 IndexService 应配套升级，保留现有数据目录、账号配置和证书；旧服务不支持当前同步协议时应提示升级，不得继续发送不兼容批次。数据库迁移保留完整备份，回滚程序时必须同时恢复兼容的数据备份。

GUI 与 MediaAgent 安装包继续自动处理客户端运行依赖，远程 GUI 不要求 Python、CUDA 或模型权重。IndexService、ModelServer 提供 Windows/Linux 组件包，模型服务部署仍按服务端说明执行。

普通组件包、离线包和部署构建显式传入发行版本；普通与离线打包脚本核对实际程序集产品版本与标签一致，避免安装包文件名已更新而程序仍显示默认版本。
