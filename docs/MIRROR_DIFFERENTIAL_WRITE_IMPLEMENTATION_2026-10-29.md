# 第二步：镜像同步差量写入

## 实现

承接索引读取耗时诊断中的第二步。生产程序保持运行；本次不发布、不迁移现场数据库。构建与测试产物位于 `E:\picer-description-sync-20261028`。

人脸批量和单行入口、人工归属的 UPSERT 增加 NULL 安全的有效值比较。同模型下未传向量时保留已有向量，模型或所属媒体变化时按原规则替换，不能跨模型继承向量。

复核状态、候选组与成员改为事务内差量对账：仅删除已不存在或发生变化的关联，仅新增或更新变化行。GUI 将照片人脸、归属和复核集合放入一个事务，读取只会看到提交前或提交后的完整状态。人工决定依然在提交前恢复。

训练制品、人物原型、策略、模型设置采用临时表接收完整快照，再按主键比较、删除缺失行、合并变化行。BLOB 使用 SQLite 值比较；相同字节不会因为新数组实例而重复更新。临时表不改变持久化 schema。重复键和约束失败使整个事务回滚。

## 泛化检查

| 路径 | 处理 |
|---|---|
| 照片人脸，批量和单行 | 跳过有效值未变的 UPSERT |
| 复核与候选集合 | 原子差量对账 |
| 训练制品、原型、策略、模型阈值 | 临时表差量合并，保留外键顺序 |
| 视频关键帧、人脸 | 比较原有 CASE/COALESCE 计算后的值，保留路径、向量、人工归属保护 |
| 视频转写、摘要、照片 AI 描述 | 保留时间版本条件，同时跳过相同值 |
| 场景摘要、地点 | 跳过相同内容；地点内容不变时不刷新本地解析时间 |
| 标签、相册、人物目录 | 跳过未变化行，人物仍受本地人工名字保护 |
| 标签与相册关联 | 已有 INSERT OR IGNORE，保留 |
| 人工编辑重放 | 保留现有幂等条件和重放语义，不能因远端快照相同就跳过人工决定恢复 |

这些优化减少持久化写入及触发器放大；完整快照仍需要读取、比较和传输。未缓存关键帧的网络转发、全量元数据下载属于后续独立链路，不宣称已解决。
