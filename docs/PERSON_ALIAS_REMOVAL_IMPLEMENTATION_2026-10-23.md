# 人物别名撤回与同步

日期：2026-10-23。开发中，未发布部署。严格构建、字段回归及人物详情窗口操作已通过，完整后续回归仍在执行。

人物详情新增“移除所选别名”：在别名下拉框中选择一项，再点击按钮。人物本名不列入可移除别名；人物名称、人脸分配和照片索引不受此操作影响。需要恢复时，在原有输入框中填写别名并点击“添加别名”。

撤回与字段操作在同一事务保存，继续使用 `person / alias:<规范化名称的 SHA-256>` 稳定字段键。空值代表明确撤回，非空值代表加入别名；不是以快照缺行推断删除。服务端沿用字段版本、已知基线、幂等回执和冲突保留机制。旧副本不能覆盖已确认撤回；读到撤回版本后，用户明确重新添加可生成新的有效版本。

应用撤回时仅查询该人物的别名，以参数化 SQL 删除匹配字段的投影，不遍历照片、视频或全库人工编辑。来源权限和人物隐私开关仍由既有同步范围控制。冲突窗口以“移除此别名”显示撤回，避免用空白内容表示用户选择。

客户端与 IndexService 均需包含本次撤回协议；旧版服务不支持该值语义，不应据此宣称混合旧版部署已经通过验收。部署前仍需完整同步协议及配套版本验证。
