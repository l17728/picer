# 照片检索与自动分类产品规格（2026-10-16）

> 实现状态（2026-10-21）：本地及远程分类整理/审核、可选 BM25+CLIP RRF、流式 Top-K 和 ModelServer 路由已实现；默认 AI 问答接入仍受质量门槛约束。实现证据见 `CLASSIFICATION_AND_HYBRID_RETRIEVAL_IMPLEMENTATION_2026-10-21.md`。

## 1. 问题与目标

照片库的描述文本需要快速、离线地检索；用户也希望照片能自动归组，减少逐张整理。产品要同时满足三点：关键词检索可解释、语义召回不强加大型服务、机器分类省事但不冒充绝对正确。

### 成功标准

- GUI/驻留程序不依赖 Elasticsearch/Milvus 等服务即可提供全文检索。
- 已存在的 VLM 描述和本地元数据能在后台进入分类视图，不重复调用模型，不阻塞用户浏览。
- 机器分类、建议、用户确认能在页面和搜索结果中区分，分类纠错可撤销且不会改动原照片。
- 新的语义融合必须通过固定查询集的效果和性能验收后才默认启用。

## 2. 用户与关键场景

1. **精确找照片**：用户搜索“红色外套”“Canon”“某年某日”，系统从文字、已确认标签和结构化条件返回匹配项，并能解释命中来源。
2. **找相近语义照片**：用户搜索“海边玩耍”，即使描述用词不一致，也可选择加入本地 CLIP 语义召回；照片语义候选与文字匹配分开计算再融合。
3. **整理图库**：用户从 AI 功能进入全图库分类页，启动后台分类；已有的描述被用于候选类别，没有描述的照片不隐式上传或计费。
4. **审阅与纠正**：用户浏览待确认类别，按单张或同类别批量确认、改类、拒绝；机器操作不覆盖人工确认。
5. **控制检索可信度**：默认搜索仅包括用户确认、可核验元数据和达到质量门槛的自动机器分类；待确认建议默认排除，用户可显式包含并能看到提示。

## 3. 功能需求

### F1：本地全文检索

- SQLite FTS5 提供倒排索引，BM25 排序。
- 保持 `han-bigram-v1` 中文字符切分和参数化 MATCH 查询；不依赖外部服务。
- 文字描述与元数据的现有索引保持向后兼容；字段权重重构必须有标注评测证据。
- AI 问答继续受结构化查询条件约束。模型只复核召回候选，不得移除明确条件。

### F2：可选 CLIP 语义召回

- 复用现有 Chinese-CLIP 本地图像向量及模型版本隔离。
- BM25 和 CLIP 分路召回，候选经硬过滤后使用 RRF 合并；不直接相加 BM25/余弦原始分数。
- CLIP 照片覆盖与视频覆盖明确区分；视频不得伪称已接入 CLIP。
- 未建索引、模型缺失、取消或搜索性能超门槛时，保持 BM25/结构化降级路径。
- 待独立离线评测达到预登记指标前，融合只做影子/可选模式，不替换现有默认问答行为。

### F3：全库自动分类与审核

分类任务只读取已有视觉描述与直接可验证的文件元数据；不自动触发新云分析。视觉场景结果默认进入待确认。自动归类仅限已验证的元数据事实白名单（方向、尺寸、相机字段存在、GPS 字段存在等），描述不得超出数据能证明的范围。GPS 不代表户外，宽高比不代表全景，拍摄小时不代表黎明/黄昏；现有 AiSceneDetector 语义启发式只能作为待确认建议。其他自动视觉分类须逐类别达到并登记离线质量门槛。完整白名单和禁用规则以[最终实现裁定](SEARCH_AND_AUTO_CLASSIFICATION_DECISIONS_2026-10-16.md)为唯一准据。

- 用户可逐项或按同一类别批量确认、纠正、拒绝、撤销本次操作。
- 机器候选和用户确认保留独立来源；纠错不会删除既有用户标签。
- 拒绝对已验证的同内容引用生效；哈希未知时只作用于当前索引项。
### F4：统一搜索语义

- 搜索含用户确认、直接元数据和达标机器自动分类；建议默认关闭。
- `包含待确认的 AI 建议`为显式 opt-in，启用时结果标记“建议/待确认”。
- 普通搜索和 AI 问答共享一致的类别状态规则。明确人物、日期、媒体类型、用户地图范围等硬条件始终保留。

## 4. 非目标

- 不部署 Elasticsearch、Milvus 或云端向量数据库。
- 不承诺每张照片都能识别或所有预测绝对正确；低证据样本允许“未分类”。
- 不默认对原始照片发起云端调用；不引入未经授权的图片上传或费用。
- 不将人脸身份自动确认为人物；沿用现有人脸建议与人工确认边界。
- 不在本交付宣称 CLIP 支持视频语义向量检索。
- 不把历史 dated reports、四项暂停的 P2 质量/硬件验收重新打开。

## 5. 产品验收

产品流程、中文交互文案和操作细节以[UX 规范](SEARCH_AND_AUTO_CLASSIFICATION_UX_2026-10-16.md)为准。实现/发布验收包括：

- 全库分类不要求先选照片；后台任务可关闭窗口后继续，增量执行、可暂停/继续/重试。
- 模型调用不会从分类页面隐式启动；不存在的描述有清晰的独立跳转入口。
- 自动、建议、人工三类状态在全库列表、详情和搜索结果语义一致。
- 用户拒绝状态持久；撤销仅影响机器来源，不删除并存的人工标签。
- 功能可在离线模式使用元数据分类、现有文字搜索；CLIP 未就绪不破坏核心路径。
- 分类与检索质量、硬件/库规模、性能阈值在评测开始前登记，按 SDD 的数据分离和统计方式验收。
