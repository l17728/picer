# 双向同步事务日志实现

日期：2026-10-23。继续落实[同步协议约束](LOCAL_REMOTE_METADATA_SYNC_PROTOCOL_DETAILS_2026-10-22.md)。本文仅描述行变更捕获基础，不代表完整双向同步已交付。

## 代码

- schema58 在既有安全迁移链中新增 `sync_metadata_row_journal`。
- 已配置 publisher 的数据库，对标签、相册、人物及别名、照片关联、位置、照片描述、分类断言/拒绝、聚类及成员、人脸标量、人物分配/拒绝/审核/纠正、视频关键帧/人脸标量和视频摘要/转录写入事务日志。
- 每条记录包含随机操作 ID、递增顺序、表内主键、操作类型和修改前后 JSON。删除保留修改前内容；业务写入回滚时日志同时回滚。分类拒绝使用其完整自然键，兼容按照片或内容哈希记录的拒绝。
- 未配置 publisher 的纯离线图库不启用捕获；远端应用沿用 `sync_suppression` 防止回传；相同数据更新不产生记录。
- 不捕获原媒体、向量、凭据或扫描缓存。不打印日志载荷。该日志仅存于本机数据库，不能绕过来源授权直接上传；其中整数 ID 仍是设备本地 ID。
- 旧库测试夹具随迁移清理新增日志表及触发器，避免生成无效的历史数据库结构。
- 媒体索引实际删除后，同步清理该媒体及其人脸关联的日志；共享视频内容只在最后一个引用删除后清理摘要、转录和关键帧日志。清理与数据库删除处于同一事务，不依赖 GUI 单一路径。

## 边界

日志目前尚未作为业务事件接入网络发送、回执与压缩。它不提供服务端因果版本，不消除旧快照复活问题，也不能替代稳定身份认领、publisher 授权、人工冲突保留或墓碑确认水位。

当前既有快照同步仍然存在[实现进度](LOCAL_REMOTE_METADATA_SYNC_IMPLEMENTATION_2026-10-22.md)列出的门槛。新实体认领、全空间设备协调和完整业务 E2E 继续待完成；尚未发布或部署本轮源码。
