# 家庭照片多标签覆盖补齐（2026-11-27）

## 目标

补齐常见家庭照片中的细分类标签，并确保已有照片在新增标签发布后会重新进入增量匹配。照片保持多标签语义；新增标签不会互斥，也不会清除用户已有的标签决定。

## 改动

- 分类预设从原有 188 个节点、179 个可分配标签，累计扩展到 230 个节点、212 个可分配标签；本轮在 202/193 的基础上新增 28 个节点，其中 19 个可分配标签。
- 新增常见宠物（兔类、小型啮齿宠物、爬行动物）、菜品与食材（蔬菜、肉类、海鲜、面食、火锅、烘焙点心）、游览地点（景区、地标）、活动（观光游览、摄影）和事件（演出现场）标签。每个标签带正向定义、排除边界、别名和分类树边。
- 已保存的旧分类树按 ID 只补入缺少的默认项和定义版本；既有自定义名称、定义、停用项、重定向和导航边均保留。升级增加分类树与发现修订号。
- 新标签的定义版本进入分类输入指纹；“增量扫描”会将旧照片识别为待更新，匹配任务会逐项检查完整的可分配标签集，继续允许一张照片同时命中多个标签。
- 将家居房间（玄关、走廊、儿童房、游戏室、洗衣房、车库、楼梯间、储藏室）和室内公共场所、自然户外、城市户外、景区户外整理为层级导航；复用已有的客厅、卧室、厨房、公园、森林、山地、河流、街道等标签，避免重复造类。
- 天气、光照时段、四季和光线条件分组；新增四季、大风、雷暴、自然光、人工照明、弱光标签，并写明仅凭日期、衣着、亮度或单一弱线索不得确认的边界。
- 所有新增标签继续作为可并存的多标签评估项；“室内”“户外”等上位标签仍保留，具体房间或场景可以与其同时命中。
- 分类浏览器按预设的导航边构建多层树；室内、户外、房间、天气、季节等节点可展开筛选其全部后代。跨维度场景（例如公园）可在“地点”和“户外”两处浏览。
- 分类树仅呈现当前有匹配照片的维度、导航节点和标签，所有节点显示照片并集数量；多标签照片在父节点计数中去重。纯分组节点不允许直接执行标签确认/排除，具体标签节点才提供审核操作。
- 维度标题改为中文（人物与主体、自然与风景、地点与空间、城市与建筑、活动、事件与节日、物品与食物、环境与光线、文档资料）。
- 已更新分类测试中的固定标签数量断言，使其由预设动态计算。
