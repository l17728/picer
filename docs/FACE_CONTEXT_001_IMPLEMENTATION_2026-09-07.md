新增 `FaceContextRankingService`，在候选已通过人脸向量阈值后，使用时间、地点、相册、场景和共同出现人物进行有限加权排序。每项加权都返回可解释证据；总增益限制为 0.08，且排序优先保留 `VectorAccepted` 候选，不能把未过身份阈值的候选提升为确认结果。

该服务只处理候选排序，不写入人物归属、不改变人工确认、不修改索引。缺少上下文时自动退回纯向量分数。
