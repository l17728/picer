范围：本轮按用户选择的“全部剩余代码与环境验收”执行，承接当前剩余工作清单、A11Y-001 和训练/语音发布门禁。不能把自动化通过、训练轮数或历史经验记录当成真实质量达标。未改动原始照片/视频，未应用新训练制品，未修改人工归类。

## 已实施

1. 主窗口增加 Ctrl+L 目录定位、Ctrl+1～5 本地页面切换、F1 快捷键帮助；保留 Ctrl+F、搜索框 Esc/Enter。远程图库使用自身搜索与焦点处理，隐藏本地工具栏，避免空 ViewModel 解引用；远程网格支持 Enter 打开原文件。
2. 主界面和远程图库使用系统前景/背景及可见焦点框，关联媒体/模型标签，给远程列表项提供可读名称。远程工具栏、人物模型信息可换行。100%/150%/200% 等效布局缩放下验证搜索框可见、焦点及网格空间；这不是切换 Windows 高对比主题或真人读屏验收。
3. 训练必须具有独立训练和验证分区；不再拿训练集代替验证集。GPU 请求补传负样本，训练准确率单独计算；修复漏计拒识、负样本分母稀释以及“排斥某个人”被错误解释成“排斥所有人物”。无负样本证据时不允许通过 FAR 门禁。
4. 评测快照仅采纳已确认正样本；照片与视频必须处于同一模型空间，避免建议标签和其他模型向量进入训练。
5. GPU 评测改为批量矩阵计算，减少逐向量 CPU/GPU 同步。真实任务曾在第 6 轮超过 120 秒，修复后续轮次通常为 4～8 秒；首次模型加载和机器同时打包时会更慢。
6. 新增模型运行状态接口，报告实际 CUDA 请求状态及已加载 ONNX provider。显式请求 CUDA 时禁止静默退回 CPU。本机启动脚本补上 CUDA 开关；修改前的 CPU 请求不计为 GPU 验收。
7. 修复制品 JSON 在传输/重序列化后的哈希不一致：v1 按签名所用强类型契约规范化，未知字段拒绝校验，篡改仍失败。未达到质量门禁的候选也原子保存，服务重启后可供审阅，不代表应用。
8. 排行榜按模型、场景和评测编号去重；仅单模型重复训练不能触发唯一 Top-1。收敛要求可用模型具有共同评测轮次，胜者通过质量门禁，重放不得增加轮数。
9. IndexService/MediaAgent 训练白名单补充只读运行状态和排行榜查询。修复 Windows PowerShell 发布脚本缺少 `System.IO.Compression` 程序集的问题。
