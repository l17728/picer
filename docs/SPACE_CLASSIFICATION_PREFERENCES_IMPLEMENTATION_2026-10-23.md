# 照片空间分类设置同步

日期：2026-10-23。schema65 开发验证中，未发布部署。

用户在分类窗口选择的自动/人工模式和人工阈值是照片空间的共同设置；两者组成一个原子字段，避免不同电脑同步到一半时出现模式与阈值错配。自动推荐值及其图库指纹仍由各自图库计算，不随账号设置覆盖，也不共享设备资源限制。

本机保存设置后进入现有上传队列；来源上传后通知照片空间的其他已登记来源，后者按各自授权范围同步索引，同时接收空间设置。远程 GUI 保存时带上读取时的字段版本；过期修改保留为冲突，界面提示从“索引巡检、同步与修复 → 处理同步冲突…”选择版本。冲突窗口用中文显示模式和阈值。原始照片和视频不参与设置同步。

schema65 仅将历史非默认设置转为待确认字段，不把新安装程序的默认值当作用户修改。已有服务端非默认设置在首次权威读取或接收修改时取得服务端版本。第一次来源自定义设置可以写入尚无设置决定的空间；已有不同决定时须按字段版本处理。

远程分类设置写入接口要求 `ExpectedVersion` 和 `ExpectedEpoch`，缺失时返回 428，过期且值不同时返回 409 并保留提议。GUI 与 IndexService 需要配套更新。接入当前人工元数据协议不代表其余字段事件、完整墓碑、版本保留与压缩已经完成。

当前新增验证覆盖默认值不制造编辑、只同步用户设置、推荐值保留、远程过期修改、本机窗口过期修改、非法载荷拒绝、旧设置迁移及真实 HTTPS 设置往返。结果待本轮构建和测试完成后补录。

首轮严格构建 0 警告、0 错误。space-preferences-schema65.trx 为 56 通过、1 失败，共 57 项。真实 HTTPS 测试发现分类设置写入沿用了 AI 分析权限，未授予分析权限的编辑设备返回 403；已将该具体接口改为要求 index.write，并新增只读设备仍拒绝的验证，修正后 `space-preferences-fixed-schema65.trx` 共 86/86 项通过，包含其他来源通知、媒体隔离、只读设备拒绝及真实 HTTPS 设置往返。之后追加的空间代次保护和实际窗口过期操作测试仍待验证。

设置字段的操作与版本变化都会触发通知，即使模式及阈值恰好相同；推荐值计算不会产生设置字段事件。来源上传期间抑制回声，再显式通知其他来源。
