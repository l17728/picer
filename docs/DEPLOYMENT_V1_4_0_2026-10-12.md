## 新用户的凭据生成边界

GUI/Agent 安装包不携带本次部署的服务凭据。独立 IndexService 首次启动先读取管理员设置的 `PICER_INDEX_SERVICE_TOKEN`，否则复用数据目录 `service-token.json`；两者均不存在时使用安全随机数生成 32 字节、Base64 编码的令牌。没有证书时创建 RSA 2048 位、自签名、有效期五年的证书，后续启动复用。更换数据目录会产生新的服务身份；显式证书轮换需要客户端重新核对公钥。

Windows 服务端默认使用当前用户 DPAPI 保护持久化凭据；DPAPI 不可用的平台会回退到未加密内容，必须依赖服务数据目录权限，Base64 不是加密。GUI 的令牌由当前 Windows 用户 DPAPI 保存。管理员通过可信渠道向新用户提供地址、令牌及证书公钥 SHA-256 指纹；用户在连接窗口确认指纹后验证并保存，流程见[安装指南](RELEASE_GUIDE.md)。

当前是每个 IndexService 共用一个访问令牌，没有按用户签发、角色权限、单用户撤销或一键邀请功能。分发一个 GUI 安装包不会自动创建账号、独立令牌或服务端；新用户自建独立 IndexService 才会生成另一套服务身份。ModelServer API Key 是另一种由管理员配置的服务端凭据，GUI 不需要持有它。
