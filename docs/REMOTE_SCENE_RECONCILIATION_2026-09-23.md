## 问题

远程镜像已经同步照片分析和场景描述，但目录场景重新按镜像数据库的时间组构建时，SQLite 图片 ID 或时间组边界可能与本地不同，导致标题、摘要和照片描述无法命中；简单按目录和时间重叠回退还可能把相邻场景错误合并。

## 修复

- 场景摘要读取在精确指纹未命中时，使用同一目录、时间重叠和照片数量相似度选择稳定回退记录。
- 场景聚类只有在精确指纹命中时才允许直接复用整组标题；稳定回退仅在模型场景拆分后应用，避免跨场景合并。
- 场景编辑在镜像数据库中回退命中旧指纹时，更新原有记录而不是创建孤立副本。
- 远程索引服务已部署包含目录分类偏好读写接口的最新版本；客户端启动后会拉取偏好、照片分析和场景描述，并在后台继续增量同步。
