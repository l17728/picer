## 用户规则

- 文件在磁盘上消失不删除索引、描述、人物、标签或缩略图；位置标注“已删除或移动”。
- 用户可以添加多个新根目录，递归扫描并按完整 SHA-256 修复照片位置；原文件不被修改。
- 相同内容对应唯一 `image_contents` 记录。`images` 是位置引用；内容分析以 `content_derivatives` 的内容哈希、分析类型和模型键持久化。现有按图片 ID 的分析表保留为兼容投影，避免破坏既有查询和同步协议。
- 引用数直接从位置记录计算，区分可用与缺失。缺失引用保留历史关联，因此可用数为零不触发内容回收。
- “彻底删除此位置记录”删除选中引用及其关联索引和缓存；其他引用仍需的共享内容继续保留。最后一个引用被用户删除时，清除共享内容、描述、全文索引和缩略图。

## 修复流程

工具菜单“修复移动后的照片索引…”可多选根目录，也可分次添加。旧的“发现缺失文件”窗口和远程图库也提供入口。

扫描新位置只读取身份信息，不解码照片、不运行 AI。重叠目录去重；单个文件或目录不可读时记录失败并继续。相同内容的旧引用与新位置一对一关联，优先保留同名文件对应的记录 ID，多出的副本新增位置引用。未匹配引用保留并标注缺失。没有历史内容哈希的记录不猜测匹配。

执行时再次验证目标 SHA-256、大小和修改时间，并检查索引是否在扫描后变化。目标路径被其他索引占用时保留原记录并报告失败，不覆盖或合并未经确认的记录。已完成的操作逐项提交，取消后可以重试。相同内容移动导致时间戳变化时，更新已有分析的来源签名，不重新分析。

远程模式将每项操作提交给索引服务，由源文件代理在本机授权根目录内再次核验后写入服务端；之后刷新镜像。用户选择的新根目录保存在本机代理授权列表，服务端不能自行扩大授权范围。当前多根目录身份修复针对照片；视频的本轮改动是以下扫描与派生数据修复。

缩略图显示缺失标记和手动清除按钮；照片右键“查看同一照片的所有位置…”展示引用数量和各路径状态。手动清除同时处理服务端、当前镜像及同源旧本地索引；该操作不删除照片原文件。

## P1 边界

1. 目录扫描逐文件隔离读取、哈希、解码及视频探测失败；文件失败仍计入已观察路径，不误判为删除。
2. 只有连续完整分页且目录枚举成功才标记未观察到的旧记录为缺失。取消、乱序、缺页和目录权限错误不执行缺失对账。
3. 新照片提取尺寸、拍摄时间、相机、GPS 和感知哈希；视频提取尺寸、时长、拍摄时间、GPS。FFmpeg 无 ffprobe 时的回退也解析时间和位置。
4. 视频内容的大小或修改时间变化后，清除旧关键帧、人脸、转写、总结、自动概念及人物分析状态，保留手动标签和概念；新媒体未提供的旧时间/GPS 等元数据不再沿用。
5. 相同内容在其他路径后生成的有效描述可按内容复用；模型指定的查询仍检查提供方、模型、提示词和地点版本。
