# 照片分类人工决定的同步补齐设计

状态：实现前核对，尚未接入 schema72；后续以针对性测试和实现记录更新状态。延续双向同步 SDD，不改变已定稿的分类来源规则。

## 已发现的缺口

现有确认、拒绝、更正和恢复操作会更新分类断言/拒绝表，通过来源快照同步。它们尚未完整进入人工字段的因果版本与冲突审核。恢复拒绝只重置当前图片的机器断言，而拒绝可能影响同一来源的多个相同内容引用；因此存在重复引用仍显示已拒绝的风险，已添加搜索结果、建议列表及旧拒绝表的回归断言。

## 保持的产品语义

人工确认与机器来源必须独立。否定或移除机器分类不能删除同类别的独立人工确认；恢复只恢复机器建议，不把建议自动升级为人工确认。不同来源的相同内容不互相复制人工决定。同一来源内共用内容的引用应保持一致，界面已有引用数量提示。

## 字段设计约束

人工确认与机器处理策略分别记录显式字段，避免将“允许机器建议”误当作“撤回人工标签”。机器策略至少表达拒绝、恢复待确认、撤销机器归类；更正原类别和确认新类别必须原子提交。版本与冲突复用现有元数据通道，不能再增加仅靠客户端时间戳排序的路径。

决定需绑定内容身份及来源。已核实的 SHA-256 可用于同来源内容归并；无哈希记录只允许绑定本引用及当时的文件版本，不能仅用可复用整数 ID，也不能因路径相同而覆盖另一来源。补齐哈希时迁移操作绑定；若出现相互矛盾的旧决定，保留审核证据，不任意挑选。最后引用清除应清理字段、回执及归属；仍有同来源引用则移交给保留引用。

来源端上传、服务端接收、远程 GUI 镜像、人工字段分页、范围收缩/恢复、依赖身份认领、冲突回执以及本地模型重新投影都须纳入同一规则。旧快照和重新分析不得覆盖已接受的人工字段；机器派生结果仍保留来源和模型版本，不将模型输出视为人工操作。

## 验收

接口实施约束：照片字段使用独立内容身份成员，不复用 `VideoContentIdentity`；确认与机器策略分别保存，概念 ID 是字段键。同来源重复引用必须共用服务端字段版本，不能只批量投影却让各引用独立竞争版本。无哈希操作绑定图库 epoch、引用和持久文件版本，补齐哈希需迁移绑定与幂等回执；换内容不重放旧决定，清除规范引用需移交给尚存的同来源引用。

接入检查点包括字段保存/读取/校验/重放、因果规范键与幂等请求、人工字段分页与冲突显示、来源端授权过滤/上行/下行/身份认领、接收端身份转换，以及远程 GUI 镜像。分类快照和模型重新投影最终必须重放有效人工字段；不能只放宽快照时间戳比较来实现恢复，否则较新的机器结果仍可能覆盖用户拒绝。按内容绑定与生命周期、分类业务事务、完整网络往返、GUI 冲突审核的顺序实现。

先固定恢复多引用的回归，再覆盖本机与远端的确认/拒绝/更正/恢复、不同来源同哈希隔离、同来源重复引用并发、未授权来源不出站、离线及范围恢复、无哈希升级、换内容、清除末引用与真实 GUI 冲突选择。旧迁移夹具必须真正移除后来触发器的依赖，不能通过关闭外键检查掩盖生产迁移问题。不得仅凭字段存在即宣布所有分类已实现双向一致。
