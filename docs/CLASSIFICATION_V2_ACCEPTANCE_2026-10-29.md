## 2. 必测矩阵

- 图：重复 ID、无效维度/父级、自环/多级环、导航联合环、跨分支同 ID、多父去重、related 不影响包含、alias 歧义、merge redirect 环/旧筛选。
- 浏览：父内 OR/父间 ALL或ANY、空包含、排除优先、建议开关、权限 scope 收缩、跨来源引用、分页/总数/树计数相同快照、取消和过期响应丢弃；500+条不截断全库统计。
- 输入：描述版本集合顺序无关；增加/修改/删除有效描述触发；无描述到有描述触发；人脸确认变化、文件替换、标签定义变化触发；别名/布局变化不触发；模型版本不得混用。
- 生命周期：失败不推进成功指纹、成功无标签与失败区分、同输入重复点击只建一次、扫描期间新事件保留下一批、任务重启回收过期租约、暂停/取消不丢已提交结果、响应丢失幂等。
- 安全/一致性：恶意描述提示注入、模型返回未知 ID/跨scope证据/非法路径/超限输出、推理途中授权撤回/文件变化/索引清除/用户拒绝/其他客户端改类；发布重新核验，不能复活旧结果。
- 同步：同来源重复内容共享人工字段、不同来源同哈希隔离、unknown hash 安全升级、最后引用清除、epoch 重置、离线 outbox、回执与回读、旧服务和部分 taxonomy 依赖。
- UX：点击图片打开原图、不可读保留预览、checkbox 不改分类、半选含义、键盘和屏幕阅读、切换条件保持焦点、无变化增量不调用模型、预算/授权/失败/未识别文案。

## 3. 质量门禁

使用用户授权的代表性样本，按主体/自然/室内场所/活动/事件/资料分层并覆盖难例和多标签；训练/校准与最终评估按内容/近重复组隔离，不能同图泄漏。人工真值至少记录标签及依据，争议项保留待定。统计每类 precision/recall、内容覆盖率、人物漏标、动态候选重复率及错误归属，不以总任务成功率替代分类质量。

定稿验收目标（非已测结果）：自动生效类别的 precision 95% Wilson 下界≥0.95，且独立正例不少于 100；不达标类别只展示建议。人物身份不经模型质量分数放行，仅使用人工确认。一般语义 recall 报告实测值和样本覆盖，不以全库强行贴标签追求 100%。稀有类样本不足时不得标为达标自动类。

明确分母：precision=TP/(TP+FP)，Wilson 区间的样本数为独立预测正例，至少 100；另外要求独立人工真值正例至少 100 用于 recall=TP/(TP+FN)，两者不能混为一数。报告标签、模型、提示、预处理、定义/发现版本以及样本采集分布。多条同图描述不当作多个独立样本，动态类别在批准结构后仍需独立质量门禁。

初轮评审新增必测：新标签加入使已有粗标签照片进入重评；向量召回遗漏不等于已处理；文本同源相关性；图片不可读不以文字单独宣称多模态完成；合并后的跨来源拒绝保持隔离与冲突审核；动态图名称/计数对撤权者不可见；旧宽义 ID 不被新细类重解释；半选点击/父级继承/同 ID 多路径及历史结果更新失败的计数文案。

## 4. 性能与运行门禁

固定 Windows x64、图库约 1 万张和至少 200 标签作为初始基线，分别记录本地缓存、远程冷缓存、并发同步及网速/RTT；测 p50/p95 和首屏，不把单次暖缓存当普遍承诺。目标：缓存树/预览首屏 p95≤1秒，组合筛选首屏 p95≤500ms（本地索引）、远端非媒体传输开销 p95≤1.5秒；无变化增量扫描 p95≤3秒且模型请求数0；UI 输入反馈≤100ms。未达标保留分段证据并优化，不缩减结果全集换速度。

LLM 总耗时单列排队、模型和网络，给出取消/进度与预算上限；不得用浏览性能目标承诺模型推理时延。每项保存/同步证明与 GUI 手工测试独立记录。当前旧产品全量测试不是本功能验收。

参考基线：Windows 11 x64、至少8逻辑核、16GB RAM、NVMe SSD、256px缩略图、分类模型并发2；服务端4核8GB SSD，测试网络分别记录20ms/100ms RTT。每条件至少30次样本，冷/暖缓存分开，记录实际CPU/磁盘型号、应用/模型版本、缓存与后台负载。达不到参考配置的现场结果独立报告。UIA 在独立GUI进程验证 Toggle/SelectionItem/ExpandCollapse/Invoke 模式与真实键盘焦点，不能仅以 RaiseEvent 或视觉树单测充当无障碍验收。

定稿新增门禁：模型完整评估范围缺项不推进成功；旧客户端全量快照不清空V2；同维度不同EmbeddingSpaceId拒绝比较；同证据ID不同摘要拒绝；条件组嵌套例、批量选择与原图点击互不冲突；在途输入变化原子保留后继工作；撤权清理与长离线客户端重建基线。已有暂停的外部硬件/质量验收不自动恢复，M0不需要这些资产；automatic 门禁仍须真实评估完成才放行。
