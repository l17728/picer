# 远程媒体读取、预览与播放实施

更新：2026-10-10。对应 `PERFORMANCE.md` 的五项改造已完成，v1.3.5 已正式发布并部署。数据库仍为 schema 45，不改写原始媒体。最终测试和发布证据见文末；仓库为私有，下载需要访问权限。

## 交付内容

- Agent 广告 `media.binary.v1` 能力，控制连接只发送指令，每个媒体读取使用独立、认证且固定服务公钥的 WebSocket。1 MiB 二进制拉取支持 offset/count，取消和背压传播到源文件。源端和服务端各限制原文件 4 路、预览 2 路，避免视频占满缩略图通道。
- 源端生成最长边 256/1600 像素 JPEG，源端、服务端各使用有界内存缓存和同键请求合并。服务浏览器双击照片先预览，可下载原图；视频缩略图缓存不再反复传输完整帧。预览缓存 64 MiB、5 分钟有效期；显式清除阻止在途任务重新发布。
- GUI 使用 ResponseHeadersRead，返回流负责释放 HTTP 响应；原图、视频下载写入临时文件，成功后原子发布，已知索引哈希必须核验。播放文件缓存上限 20 GiB，分块缓存每个读取器 32 MiB，下载并发默认 2、可选 2–4。
- 工具菜单配置播放器和自动/优先流式/下载策略。自动模式只对程序名与产品信息均匹配的 VLC/mpv 使用网络播放，不确定时下载；首次播放或用户选择时再次显示设置。收到首批 HTTP 数据只能证明播放器开始读取，不能证明支持所有编码；窗口保留“改为下载后播放”按钮。
- GUI 使用自包含 Kestrel 在随机 loopback 端口提供一个视频的短期地址，校验随机能力路径、Host、来源和方法。不向播放器传递服务 URL、固定公钥或长期令牌。关闭播放窗口撤销入口并取消上游，空闲 30 分钟停止；持续读取不误判为空闲。
- 端到端 Range 支持 HEAD、206、Content-Range、416、If-Match、尾部索引、相邻分块预取、重复跳转缓存。最多一个失败读取重试，版本不一致直接中止，不混合分块。

## 文件身份与清理

普通用户不一定能读取 NTFS USN。原文件跨请求版本使用不透明租约，源端保留 FileShare.Read 的只读句柄，阻止读取期间写入或替换。每次 Range 必须复用 HEAD 返回的租约；不同路径、释放或重连后的旧租约拒绝。客户端每 30 秒续租，退出主动释放；失联且无活动读取 2 分钟后回收，最多 32 个租约。读取不会修改原文件，但编辑器在播放期间可能遇到共享冲突，应先关闭播放。

显式索引清除取消对应源读取并等待退出，清空派生内存缓存及 GUI 播放缓存；未能删除仍被外部播放器打开的缓存时报告失败，保留可重试的索引状态，不把失败写为成功。清除失败不再使后续下载永久处于取消状态。源端路径仍必须位于授权根内，拒绝重解析链接。

## 测量与验证

日志记录字节数、源准备/解码/编码/读取/发送、队列等待、客户端传输和预览解码耗时，不记录原文件路径、媒体内容、长期令牌或 AI 文本。单次耗时不能单独推断磁盘或带宽瓶颈。

`dotnet run --project tools/Picer.Benchmarks -c Debug --no-build -- --media-transfer` 可重复运行 1/2/4 路基准，输出首批字节、冷暖跳转、下载吞吐、实际源字节和进程峰值工作集。其来源是每块延迟 25 ms 的合成 16 MiB 数据，不是公网、真实磁盘或显示首帧测量。

回归覆盖真实 HTTPS + Agent WebSocket 的大文件首尾 Range、原图缩图及合并、过期租约、读句柄释放、并发上限、变化版本拒绝、清除失败恢复、本机代理鉴权和取消。另有 RuntimeComponent 测试使用包内固定 FFmpeg 解码超过 80 MiB 的尾部 moov 视频，验证首帧及前后跳转不需要完整下载。FFmpeg 仅用于测试解码器和原有源端视频处理；远程 GUI 播放通过用户选择的播放器完成。

## 安装与兼容边界

GUI 包新增自包含 ASP.NET Core/Kestrel 运行库，安装器校验对应 DLL，不要求用户单独安装服务器运行时、Python 或 CUDA。Agent 和 IndexService 应同步升级；旧 Agent 不广告新能力时保留旧协议回退，旧协议的整文件 64 MiB 限制仍存在。

混合版本下的 HEAD 能力探测直接返回 405，客户端据此选择下载，不要求旧 Agent 上传完整视频。回归使用 80 MiB 文件和不支持二进制通道的驻留端，验证无原文件请求。默认播放器未显式指定时，本地文件和下载完成的文件仍通过 Windows Shell 文件关联打开，以保留商店应用及关联参数。

候选记录：v1.3.0 的 CI 38035182437 通过 637 项单元和 88 项桌面测试，发布因默认 Windows 文件关联兼容修复主动取消。v1.3.1 的 CI 38035878228 在真实服务视频元信息探测阶段连接失败；复查发现新服务对旧 Agent 的 HEAD 会触发整文件读取，修复后以旧 Agent 再次通过真实索引、照片/视频缩略图及能力回退探针。v1.3.1 发布也主动取消；两标签保留，不将取消的候选写为正式发布。v1.3.2 对应 432dea8，保留为未公开候选。
