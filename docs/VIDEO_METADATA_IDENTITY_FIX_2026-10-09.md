## 多模型人脸镜像

此前导入视频人脸时先使用默认模型插入所有行，再更新真实模型。同一关键帧、同一序号存在不同模型结果时，第二行会触发唯一键冲突，导致整批元数据回滚。

现在插入与模型归属一次完成；同模型的精简响应仍保留已有向量，模型发生变化时不会沿用旧模型向量。缺少模型字段的旧响应保留已知模型信息。

## 内容级人工编辑

schema 45 为编辑日志增加内容身份，并记录操作首次绑定的身份。完整有效 SHA-256 是跨库身份；未知摘要只使用当前数据库 epoch 与内容 ID 组成的本地身份，不凭文件名、大小或时间猜测跨库对应关系。

同内容不同引用上的标签、概念编辑按更新时间及操作 ID 选取唯一胜出事件。输出和接收均映射到仍存在的代表引用；原始引用后来指向新内容时，迟到事件不会覆盖新内容的编辑日志。新人工操作的时间也会超过该内容字段已知的最新时间，避免另一副本上的未来时间戳令新选择失效。

缺引用的旧事件保留不可重新绑定的 orphan 身份。未知摘要补齐后，本地编辑升级为验证过的内容身份。删除或替换一个引用时，将共享内容编辑转给剩余引用；最后引用移除时删除关联编辑及操作绑定。

同步只导出内容字段的胜出事件，返回的确认也对应胜出操作；过期副本事件不会持续进入待同步列表。

## 升级及兼容边界

schema 45 沿用关闭数据库后的 DB/WAL/SHM 备份和暂存迁移机制。测试夹具真实撤销 45 后再验证旧版升级，未直接修改旧版本号来伪造结构。

JSON 新增的 `videoContentIdentity` 为可选字段，旧请求首次接收时绑定当时已有内容，已经接收过的操作保持首次身份。旧服务端不理解新身份，因此多引用编辑和迟到事件的完整保护要求服务端与客户端一并升级；仅 JSON 字段兼容不代表旧服务端具备新一致性语义。未知 SHA 的本地编辑不会被另一个数据库错误套用，补齐摘要后才具备跨库同步身份。

新增回归覆盖多模型导入、向量省略与模型更换、跨引用 LWW、内容替换与迟到事件、缺引用重试、未知身份跨库隔离、删除引用转移、跨引用确认、未来时间戳，以及真实 44→45 迁移。验证结果由主线程统一构建和测试记录。

最终核验及补充的跨库身份升级、历史绑定清理回归见[剩余代码复查记录](RESIDUAL_CODE_FIXES_2026-10-09.md#验证记录)。视频未知哈希编辑暂留本库，补齐 SHA 后发送；接收方不会保存无法解析的外库本地身份，已经验证的 SHA 身份仍不可改绑。
