修复权威服务镜像只追加字典和场景描述、未传播删除的问题。仅 `ServiceMode` 且增量镜像协议可用时，对标签、相册、人物字典执行差集删除；照片关系原有对账继续按镜像归属限定范围。场景描述集合为非空引用时按 fingerprint 对账，空数组代表全部删除，null 代表旧服务不支持该集合、保持本地数据。

`metadata_edits` 是长期保留的字段寄存器，不等同于待发送队列。同步客户端只在完整同步成功后发布本次服务确认的 operation ID 集合。字典对账检查当前寄存器：未确认的本地编辑保留对应字典项；已确认历史编辑不阻止权威删除，并随已删除字典项清除，避免后续重放复活历史状态。请求期间新编辑拥有不同 operation ID，因此不会误认为已确认。首次启动或未确认请求采用保守保留。

回归源码 `MirrorCatalogReconciliationTests` 覆盖权威开关、已确认/未确认编辑、删除后重放、新编辑与旧确认竞争、冷启动保守保护、场景集合 null/空数组兼容。统一构建测试由主审查执行。
