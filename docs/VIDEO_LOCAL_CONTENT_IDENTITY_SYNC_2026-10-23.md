# 无哈希视频人工元数据同步

2026-10-23，schema67 开发中，未发布部署。

## 根因与修复

没有 SHA-256 的视频用 `local:<数据库 epoch>:<内容 ID>` 绑定人工标签和分类决定。来源数据库与 IndexService 数据库的 epoch、内容 ID 不相同。原先只翻译视频引用 ID，没有翻译内容身份；接收端找不到目标时跳过业务应用，但批次仍可能返回接受数量，造成已同步的假象。

视频上传批次现在同时携带来源内容身份，在同一事务建立按 publisher 隔离的映射。上传人工决定时按该映射转换，下行时转换回来源身份。不存在映射、身份格式错误或身份被重新绑定时，批次明确拒绝并给出错误代码。不能用文件名、路径或其他来源的相同整数 ID 进行猜测。

映射属于索引数据，与 publisher、视频内容通过外键关联；显式清除最后一个内容引用时随内容删除。原始媒体不读取、不修改。已有 SHA-256 的人工决定继续使用哈希身份和既有来源归属校验。

协议版本提升为 3，注册时检测服务支持，避免新客户端把旧服务忽略字段误认为成功。发布状态和持久快照保存各自协议版本；旧版本已完成的同步不会触发“没有变化”短路，会进行一次完整索引上传以建立映射，此后恢复增量。未完成快照的结果按其实际协议版本记录，不能冒充已完成新协议的基线。
