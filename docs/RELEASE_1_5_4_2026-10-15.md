# Picer v1.5.4 发布记录

## 变更

- 修复远程图库缩略图遇到临时 429/503 后立即重试、造成请求风暴并拖慢索引加载的问题。可见缩略图并发限制为 2；单张图片失败后按 5 秒起步、最长 60 秒的指数退避重试，成功后清除退避状态。
- 增加远程登录已有照片空间的逐步操作指南，明确服务地址文件、设备认证文件、已有账号/空间选择，以及本地索引上传前提。

## 本地验证

- `dotnet build picer.sln -c Debug --no-restore --warnaserror`：通过，0 警告、0 错误。
- `Picer.Tests`：408/408 测试断言通过；本机 VSTest 在最后一个测试结束后仍残留测试宿主，10 分钟 hang detector 将进程判为异常退出。TRX 中无失败项。正式发布仍以 GitHub CI/Release 工作流的进程退出状态为准。
- `Picer.E2E`：最终完整复跑 94/94 通过。第一轮 3 项固定时限失败在关闭旧 GUI、单独复跑后均通过；对应记录为环境时序抖动。
- `ThumbnailRetryTrackerTests`：2 项通过；当前 GUI Release 构建与本机热更新的结果见[缩略图可靠性记录](THUMBNAIL_RELIABILITY_2026-10-15.md)。
