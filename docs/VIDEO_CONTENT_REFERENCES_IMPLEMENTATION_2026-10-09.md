## 数据语义

schema 44 新增 `video_contents`。`videos` 继续表示目录中的文件引用，以 `content_id` 指向内容。已有完整 SHA-256 相同的视频合并到同一内容；缺少摘要的历史文件保持独立，后续获得可靠摘要才重新关联。

`video_keyframes`、`video_transcripts`、`video_summaries`、`video_detected_faces`、`video_tags`、`video_visual_concepts` 的 `video_id` 改为内容外键。人脸拒绝关系继续关联稳定的人脸 ID。摘要、转录、关键帧、人脸及标签无需为每个路径复制。文件路径、来源、是否存在仍由每条 `videos` 引用独立维护。

删除一个引用不影响其他副本；最后一个引用删除时，内容行及派生数据通过外键级联删除，内容全文索引同时清除。正在运行的任务不能通过已经删除的引用创建新内容。匿名请求费用账本与媒体索引分离，不因副本数量增加费用记录。

文件内容变化会先分离该引用，避免删除其他相同内容副本的分析。异步摘要返回时重新验证当前文件内容；如果引用指向的内容已改变，只登记已经发生的匿名费用，不将旧分析写入新内容。

## 迁移、查询和镜像

迁移在已有关闭文件备份与暂存迁移保护下执行。七个派生关系表重建外键，按内容与时间合并重复关键帧，按模型及检测位置归并重复人脸。无法同时作为当前状态保留的历史人工判断保存在 `video_content_decision_history`；拒绝关系归并到保留的人脸。该历史也由内容外键管理，不会越过最后引用删除而残留。

视频全文索引使用负内容 ID，每份描述仅存一份；BM25 命中后投影到所有有效引用。目录描述、人物筛选、标签、概念及关键帧读取均显式经过内容关联。

镜像协议继续传输可用的视频引用 ID，本地解析成内容 ID。导出时选择仍存在的引用，因此最初代表引用删除后仍可同步。权威元数据刷新可清除服务端已不存在的帧、人脸、转录及摘要，省略的人脸向量则保留已有缓存。

## 回归覆盖

- 相同内容、多路径、单份分析与全文文档，以及 BM25 多引用结果。
- 删除代表引用保留内容，删除末引用清除派生数据，迟到写入失败。
- 一份副本内容变化、未知摘要恢复后的分析关联。
- 权威镜像删除同步及引用 ID 与内容 ID 不同的情况。
- 真实 schema 43 副本迁移、人工判断保留及外键完整性。
- 索引修复新增引用不复制模型费用和派生关系。

原四项 P2 环境验收仍按用户要求暂停；本次修改没有重新调用付费模型或操作真实媒体库。
