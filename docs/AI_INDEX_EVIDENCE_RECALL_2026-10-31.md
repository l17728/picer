# AI 问答索引证据召回修复

状态：开发、专项及完整桌面回归、本地 GUI 部署与启动验收完成；未发布正式版本。

## 目标与边界

修复烹饪标签已经存在但默认问答不召回的问题，并排查各类索引证据的入口、组合和结果保留。真实图库的语义真值不由程序掌握，模型描述、自动标签、GPS 和时间记录也可能有误，不能承诺任意问题的召回率、精确率均为 100%。验收采用明确正负样本、硬条件和真实索引只读副本，不把测试通过率当成全图库质量指标。

## 实现

- 普通搜索与 AI 问答默认包含有效分类建议，保留关闭选项；清空普通搜索或问答输入不重置选项，显式重置筛选恢复默认值。
- 分类证据区分人工确认、人物证据、当前成功模型建议、历史模型分类、当前描述派生建议。继续检查内容身份、停用分类、冲突和当前状态，离线未能重新验证时排除模型建议及历史模型分类。
- 原问题明确出现的分类名称和别名通过分类树识别，不依赖规划模型完整保留原词；避免把规划模型自行增加的非字面视觉词当成额外硬条件。单词边界和局部否定词用于避免明显的误加词；这不是完整自然语言否定/布尔解析器。
- 每个视觉条件可以由不同索引通道提供证据；同一条件的同义词按可替代处理，不同条件求交集。例如“烹饪”分类加“红色围裙”描述能够共同命中，但只满足一个条件不能当成完整索引匹配。
- 补齐相册名称、相册描述、视频手工标签与视频有效视觉概念的文字召回。照片描述、已接收本地视觉描述、目录描述、标签和地点文字继续参加查询；相应证据进入模型解释样本。
- 人工确认人物交集、时间、有效媒体引用和已知 GPS 冲突仍是独立约束。地点文字兜底后再次检查视觉条件；无法解析的地点不能仅凭活动词命中。
- AI 索引召回使用内部全集读取，不再静默保留前 50 或前 200 项。语义相似通道仍是受限的可选近邻候选，不等同于全集或身份、地点事实。
- 模型解释只接收有大小上限的样本，中文不以 Unicode 转义膨胀；模型可以排序，但不能凭空增加 ID 或删除已有索引命中。复核网络失败、超时仍保留索引结果并明确提示。
- 人物约束读取轻量名称目录，避免无必要的全人物统计。

## 证据覆盖

| 信息 | 用途与限制 |
| --- | --- |
| 分类树、别名及各来源标签 | 分类召回、组合匹配、结果来源提示；不把模型建议自动转成人工确认 |
| 照片描述、本地视觉描述、目录描述 | 文字召回和解释样本，保留来源；文字匹配不是视觉真值 |
| 手工标签、相册名称与描述 | 独立文字证据，不要求照片已有 AI 描述 |
| 人物名称及别名 | 以人工确认人脸关联强制求交集；不以模型猜测替代身份 |
| 拍摄时间、时段、GPS、地点文字 | 结构化约束和有提示的文字兜底，已知 GPS 冲突排除 |
| 视频转写、摘要、标签和有效视觉概念 | 视频召回；拒绝的手工概念不恢复为有效分类 |
| 当前模型的中文语义向量 | 可选相似候选，保留范围及不确定性，不作为人工身份事实 |

## 验收计划与记录

新增/扩展用例覆盖：默认烹饪建议召回；规划漏词与改写；复核空结果或编造 ID；205 条结果不被旧上限截断；跨通道组合正负样本；相册和视频手工标签；地点兜底不能绕过活动条件；无索引不能编造结果；复核网络失败；历史描述建议与冲突；GUI 清空输入不改变建议选项。

真实图库验证使用 SQLite 在线只读备份生成隔离副本，读取服务端当前分类副本，在内存中模拟规划漏词和空复核结果，不发送真实问题或图片给外部模型、不修改源库。最终构建、测试计数、实际返回 ID 和部署结果在验收完成后补录。
