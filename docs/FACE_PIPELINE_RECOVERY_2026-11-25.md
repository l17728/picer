# 人脸链路剩余修复（2026-11-25）

## 实现

- 常驻 GPU worker 的排队及执行共享总时限，默认 120 秒，读取 PICER_GPU_WORKER_TIMEOUT_SECONDS（1～600 秒）。排队取消不影响正在运行的 worker；执行取消、超时或最终失败清理进程，释放信号量，后续请求重新启动。
- 媒体代理人脸任务的图片读取、模型 HTTP 请求和响应正文使用独立三分钟时限，超时返回 face_request_timeout。

- 前一提交已接入远程分析后同步与自动归类；本阶段继续现场验收。
