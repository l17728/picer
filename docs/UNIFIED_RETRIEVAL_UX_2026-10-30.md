# 统一问答与分类故障 UX

AI 问答为日常搜索入口，显示“理解条件 → 索引候选 → 补充语义候选 → 最终结果”。先到结果标明候选，语义不可用时说明只完成了哪些通道。纯人物/地点/时间问题不显示无意义的语义等待。每条结果保留来源依据，模型解释不改程序确认的人物与数量。

“语义索引管理”负责查看覆盖和增量构建，不在每次提问时启动全库编码。零覆盖、服务不可用、权限不足分别提示，不能都显示“无结果”。不新增默认远程授权。

分类加载失败时，覆盖栏立即改为“分类读取失败”或“需要更新设备授权”，状态栏和错误详情一致；显示“重试”和现有配对入口。权限不足指向“连接账号/更新设备授权”，说明重新授权后重开分类页面。成功前禁用依赖有效快照的操作。刷新失败仍保留上次结果且明确不是最新状态；取消/关闭不弹失败。

人工审核遇到冲突时保留待处理记录，要求刷新后重新确认，不自动覆盖别的设备决定。后台待同步、服务已接收、回读确认、冲突为不同状态。新增任务和同步队列变化不造成当前选中项和预览跳动。
