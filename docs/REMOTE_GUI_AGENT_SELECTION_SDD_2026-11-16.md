# 远程 GUI 与来源驻留程序自动判定设计

## 目标

GUI 通过账户设备访问远程索引服务；驻留程序只在本机存在可访问来源目录时启动。远程相册浏览、分类、搜索和已有缩略图不依赖本机来源目录。

## 判定规则

1. 读取本机已登记来源目录，并过滤不存在或不可访问的路径。
2. 至少有一个可访问路径时，才创建临时 agent 凭据、申请 agent 授权并启动本机 agent，传入来源目录。
3. 没有可访问路径时，只创建临时 GUI 凭据、申请 GUI 授权并跳过所有 agent 授权、启动和 WebSocket 检查。
4. GUI 始终验证服务健康、服务身份和 GUI 账户连接；agent WebSocket 只在 agent 启动时验证。
5. 原图或实时缩略图请求失败时，提示对应远程来源 agent 离线，不阻断索引浏览。

## 一致性

账户设备和 agent 设备使用独立授权与凭据；服务地址、SPKI 指纹和后端设备认证配置必须来自同一次服务发现。

配置流程使用临时凭据路径和临时 CNG 密钥。所有登录、授权、导入和连接验证成功后，才通过原子替换发布新的 GUI/agent 凭据；失败时删除临时文件和临时密钥，保留原凭据及其私钥。后端配置文件也采用临时文件加原子替换。成功后自动重启 GUI，刷新长期持有的账户客户端、Gateway 和缓存；回滚后同样重启 GUI。

## 验收用例

- 新电脑无来源目录：GUI 配置成功，agent 不启动，远程索引可浏览。
- 有一个可访问来源目录：GUI 和 agent 均连接新服务。
- 来源目录失效：GUI 仍可浏览索引，agent 不启动。
- 远程来源 agent 在线：新电脑不需要本地目录即可浏览远程缩略图。
- 服务切换失败：账户、agent、后端配置恢复到切换前状态。
- 无来源目录时不创建 agent 凭据、不申请 agent grant、不启动 agent。
- agent 授权失败时，无来源目录的 GUI 配置仍可成功。

## 评审修订项

本版根据领域专家评审补充了四项强制约束：无来源目录不创建 agent；临时凭据和 CNG 私钥原子发布；失败后重启或刷新 GUI 连接对象；远程 GUI 流程不依赖 agent 授权。
