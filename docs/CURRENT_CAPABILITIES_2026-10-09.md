# 当前能力与验证状态

阶段结论（2026-10-10）：v1.3.5 已交付，当前进行目录描述启动延迟的维护修复及性能复查。下表记录既有交付证据，文末单独记录尚未部署的源码修改；四项暂停的质量/硬件验收仍不计作已通过。

发布基线为 [v1.3.5](https://github.com/l17728/picer/releases/tag/v1.3.5)，schema 45；私有仓库下载需要访问权限。测试、安装及部署证据统一见[媒体实施记录](MEDIA_STREAMING_IMPLEMENTATION_2026-10-10.md)，后续源码维护与已发布版本分别记录。

GUI/独立 Agent 中文当前用户一键安装器已实现，包含自包含 .NET、app-local MSVC CRT，代理 tools/ffmpeg 目录同时提供 FFmpeg、FFprobe 及许可证并自动发现。纯远程 GUI 不需要 Python、CUDA 或模型 runtime，也不检查本地 runtime。首次从“文件 → 连接索引服务…”完成无凭据证书发现、指纹确认、固定公钥验证及 DPAPI 保存，无需编辑 JSON。模型端 setup-modelserver.py 默认 CPU 的实际验收已通过；GPU 和授权模型依然按服务端配置。详见[安装实现记录](INSTALLER_IMPLEMENTATION_2026-10-10.md)和[安装指南](RELEASE_GUIDE.md)。

v1.3.5 的部署、安装包校验和真实服务验收证据统一见[媒体实施记录](MEDIA_STREAMING_IMPLEMENTATION_2026-10-10.md)。
