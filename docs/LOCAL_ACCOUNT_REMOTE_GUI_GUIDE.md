# 在另一台电脑登录已有照片空间

本指南适用于：照片已由原电脑建立索引并同步到你的 IndexService 照片空间；现在要在另一台 Windows 电脑安装 GUI，并使用**原有账号和原有照片空间**查看这些索引。

## 在新电脑安装并登录

1. 打开 [Picer 最新正式 Release](https://github.com/l17728/picer/releases/latest)，下载该版本的 `Picer-v版本号-win-x64-setup.exe`，双击安装并启动 Picer。私有仓库需要先登录有访问权限的 GitHub 账号。远程浏览只需 GUI；新电脑不必启动 MediaAgent，也不需要自行安装 Python、CUDA、FFmpeg 或本地模型。
2. 在 Picer 主窗口左上角点 **文件 → 连接索引服务…**。
3. 在“连接索引服务 / 本地模式”窗口选择 **远程模式（HTTPS 索引服务）**，再点 **登录照片空间 / 导入设备认证文件…**。
4. 在“登录照片空间”窗口，如果管理员或原电脑提供了 `.picer-service` 文件，点 **导入服务地址文件…**，选中该文件。它只填写服务地址，不含账号或登录凭据。没有该文件时，在 **HTTPS 服务地址** 框输入管理员提供的完整地址（包含 `https://` 和端口）。
5. 点 **在浏览器中注册或登录**。首次连接会先显示服务地址和证书 SHA-256 指纹；通过可信渠道核对后，在确认框点 **是**。浏览器随后打开配对网页。
6. 在网页中登录**原来建立/拥有该照片空间的账号**。选择该账号下已经存在的照片空间（例如 **原有照片空间（owner）**），不要创建新账号或新空间。确认网页显示的设备名称/指纹对应这台新电脑，批准 GUI 设备请求，并下载这次配对生成的 `.picer-auth` 文件。
7. 回到 Picer 的“登录照片空间”窗口，点 **导入设备认证文件…**，选择刚下载的 `.picer-auth`。验证成功后，点 **使用此照片空间**。
8. 回到“连接索引服务 / 本地模式”窗口，确认状态显示的账号和空间正确，然后点右下角 **保存并重启**。
9. Picer 重启后会从选中的远程照片空间加载目录、照片和视频索引。首次载入可能需要等待同步完成；之后可在图库中浏览。若仍为空，重新打开 **文件 → 连接索引服务…**，检查当前登录账号和空间是否与原电脑上传索引时完全相同。

## 两种文件和两个电脑角色

- `.picer-service` 是服务地址文件，可以在新电脑导入；它不登录账号，也不授权访问。
- `.picer-auth` 是绑定到发起配对的那台电脑的设备凭据，不能拿另一台电脑生成的文件代替。请在目标电脑的 Picer 中发起请求，再从网页下载并导入。
- 远程 GUI 读取照片和视频的**索引及缩略图**，不需要新电脑上的驻留程序。原始媒体仍在来源电脑；要远程读取/播放原图或视频，来源电脑的 MediaAgent 必须在线并保留原目录授权。
- 如果旧索引尚未上传到这个账号的照片空间，新电脑登录后不会自动看到仅存在于另一台电脑本地数据库的索引。应先在原电脑点 **文件 → 索引服务状态**，在打开的窗口中点 **上传到我的照片空间…**，将本地索引纳入同一空间。
- 在新电脑选择远程模式不会删除原电脑的本地索引。两种模式的数据位置不同；切回本地模式即可访问该机本地索引。

## 本地索引迁移到已有账号空间

在保存本地索引的原电脑打开 Picer，点 **文件 → 索引服务状态**，再点 **上传到我的照片空间…**。按窗口提示登录同一个已有账号、选择要合并管理的空间，并按网页授权要求批准索引写入。上传完成后，再按本指南在新电脑登录该账号和空间。

不要为了让新电脑看到旧照片而新建一个账号或空间；新空间与原空间彼此隔离。索引同步不会搬动原始照片文件。

## 登录后如何检查同步

1. 在主窗口点击 **工具 → 索引巡检、同步与修复…**。
2. 点击 **巡检并同步用户空间**。程序按各台来源电脑原先授权的范围协调同步，窗口显示逐来源回执；离线电脑需要上线后才能完成自己的工作。
3. 如果显示编辑冲突，点击 **处理同步冲突…**，查看两边的内容并选择保留的版本。程序不会用模型重算覆盖用户已经确认的决定。

首次连接需要建立镜像基线，大型人脸元数据可能需要数分钟；图库可先显示已经读取的目录和照片。后续编辑由操作及服务通知触发同步。手动巡检无需重新导入认证文件，也不会把其他来源电脑的图库复制到本机。

只有原始媒体发生移动、需要寻找新位置时，才在同一窗口点击 **添加根目录…**，选好新位置后点击 **开始修复索引**。未找到的文件保留索引并显示“已删除或移动”，不会自动清除。
