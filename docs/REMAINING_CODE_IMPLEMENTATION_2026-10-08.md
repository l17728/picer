范围：承接六项代码盘点，并实现用户追加的“AI 菜单选择目录树节点，对整个子树的照片和视频增量描述”。本轮不放宽人脸质量门禁，不执行未经产品界面授权的云端批量分析，不修改原始媒体文件。

## 代码改动

| 项目 | 实现 |
|---|---|
| 目录媒体描述 | AI 菜单“描述目录中的照片和视频…”打开目录树选择窗口。包含视频专属子目录和已注册媒体源，预览照片/视频总数、已有描述、待处理数；开始时分页扫描整个子树，导入新增媒体，再按快照执行。支持取消、逐项失败继续、再次运行跳过已完成项。扫描拒绝目录链接及越出媒体源的路径，排除派生关键帧缓存；无权访问的目录明确失败，不静默当成空目录。 |
| 视频描述 | 缺少关键帧时调用 IndexService/MediaAgent 提取；远程帧经过下载及图像验证后生成最多 12 帧拼图；使用视频总结模型并结合已有转写。无转写不冒充已做语音分析。 |
| 增量判定 | 复用任意已完成模型的非空照片描述/视频摘要，但文件大小或修改时间变化会失效。照片与视频的同步契约携带原文件签名，解决同步后签名变成 0/空字符串导致重复分析的问题。对旧同步丢失签名的记录，仅在扫描确认文件与原索引一致后恢复签名；照片另核对 SHA-256。真实镜像发现 58 条照片描述受旧问题影响，已添加回归验证。 |
| 中文文字检索 | 保留原始描述，并新增离线汉字单字/相邻双字及拉丁词编码索引。明确这是字符切分，不是假称词典分词。查询输入转换为受控 FTS 表达式，SQL 参数化；SQLite FTS5 BM25 在截断候选前排序。 |
| AI 问答 | 照片和视频使用共同检索边界；保留人物人工确认、日期、时段和其他结构化条件。模型仍只负责规划问题及复核已检索的候选，不允许编造媒体 ID。 |
| 内容身份与派生数据 | schema v41 增加外键指向 `image_contents` 的内容级派生存储，按内容哈希、种类和模型/条目键隔离保存人脸、视觉分析、描述及人工审阅证据。记录 ID 表作为现有界面和同步的兼容投影保留；新副本可恢复派生数据，删除单个物理索引不清空内容级结果。 |
| 内容文字投影 | 内容级文字及其 FTS 与物理记录分离；按内容查回当前可用路径，保留分词版本。避免把历史绝对路径作为共享描述的正文复制。 |
| 缩略图 | 本地索引和 LocalGateway 使用 SHA-256、尺寸、缓存版本生成共享键；删除单个记录的缓存不删除同内容共享缓存。无完整哈希的旧记录继续使用旧键。 |
| 视频组合筛选 | 视频人物、GPS、标签和视觉概念联合筛选，支持标签/概念编辑；人工拒绝优先于模型建议。视频标记接入字段级同步日志，删除标签也能同步。 |
| 服务依赖与凭据 | WindowsCredentialStore/ICredentialStore 下沉 Core，凭据目标名称不变。ViewModel 的静态 AppServices 调用改为构造注入 ClientServices，其中含 IIndexGateway、镜像仓储及授权操作；组合根仍负责服务生命周期，远端原件经网关读取。 |

## 迁移与兼容

- v40：中文相关性索引、同步触发器、视频标签/概念表；既有媒体文字回填。
- v41：事务内建立内容派生存储和内容文字索引，回填并恢复缺失投影；描述和视频转写同步触发文字索引更新，既有描述不需要重调模型即可进入 BM25。失败事务回滚。不删除原记录或更改既有人物确认。
- 选择保留记录 ID 兼容投影，避免一次性改变人脸 ID、历史校准快照和客户端协议；实际共享所有权由内容级外键表承载。不是声称旧表所有 `image_id` 字段已经消失。
- 实际数据库升级前停止 GUI/驻留程序，整文件备份数据库与现存 WAL/SHM；先在备份副本上检查完整性、外键及原有人物确认/不分类/描述行是否保持。
- Linux 部署脚本同时备份数据库与程序。升级失败时同步回滚数据库、WAL/SHM 和程序，避免旧程序使用新触发器；延长健康检查等待以容纳迁移。
